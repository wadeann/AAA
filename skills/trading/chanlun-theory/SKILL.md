## 一、理论架构与层次 (六层架构)

缠论用公理化方式将市场走势划分为六层递进结构：

```
第1层：K线（原始数据，需经过包含处理）
  ↓ 包含处理
第2层：分型（顶分型、底分型）
  ↓ 画笔
第3层：笔（相邻顶底分型之间的连接）
  ↓ 线段
第4层：线段（至少3笔连续组成，次级别走势类型基础）
  ↓ 中枢递归
第5层：本级别走势类型（含中枢的盘整 / 趋势）
  ↓ 级别递归
第6层：更大级别走势类型
```

### 关键概念与判断标准

| 概念 | 理论定义 | 判断与计算规则 |
|------|----------|----------------|
| **K线包含处理** | 相邻两K线存在包含关系时进行的合并处理 | 向上走势高高取高、低低取高；向下走势高高取低、低低取低（顺次处理，不具传递性） |
| **顶分型** | 3根包含处理后的K线中，中间K线极值最高 | 中间K线高点最高、低点最高。铁律：顶点必为顶分型 |
| **底分型** | 3根包含处理后的K线中，中间K线极值最低 | 中间K线低点最低、高点最低。铁律：底点必为底分型 |
| **笔** | 两个相邻顶底分型之间的连接 | 顶底分型之间至少隔着1根独立K线（不含分型极值K线） |
| **线段** | 至少由3笔连续重叠组成 | 向上线段看向下笔的特征序列顶分型；向下线段看向上笔的特征序列底分型 |
| **中枢** | 连续3个次级别走势类型重叠的部分 | 区间 $ZG = \min(g_1, g_2, g_3)$, $ZD = \max(d_1, d_2, d_3)$，中枢区间 $[ZD, ZG]$ |
| **量化代理中枢** | 工程实现中以包含处理后的连续3笔重叠近似严格中枢 | 必须标注为“三笔重叠代理”，不能冒充连续3个完整次级别走势类型；相邻滑窗反复重叠通常属于中枢延伸/内部收窄，不应逐个计为独立中枢 |
| **中轴** | 中枢区间的中心位置 | $Z = \frac{ZG + ZD}{2}$ |
| **盘整** | 完成的走势类型只包含1个本级别中枢 | 只有一个中枢 |
| **趋势** | 完成的走势类型包含2个以上同向本级别中枢 | 同向中枢间区间无重叠（$ZG_{n} < ZD_{n+1}$ 表示上涨趋势） |

## 二、核心定理体系

### 1. 第一原理：走势终完美
> "任何级别的任何走势类型终要完成。"
- **含义**：走势必完美 = 中枢必然形成；走势必完美 = 走势可被唯一分解；完成之后必然转化为其他类型的走势（上涨→下跌或盘整；下跌→上涨或盘整）。

### 2. 中枢三大定理
- **定理一**：趋势中，连接两个同级别中枢的必然是次级别以下级别的走势类型。
- **定理二**：盘整中，离开或返回中枢的走势类型必然是次级别以下的。
- **定理三（破坏定理）**：某级别中枢的破坏 = 次级别走势离开该中枢 + 随后的次级别回抽走势不重新回到该中枢区间 $[ZD, ZG]$（第三类买卖点的几何来源）。

### 3. 背驰-转折定理
> 某级别趋势的背驰将导致：该趋势最后一个中枢的级别扩展、或该级别更大级别的盘整、或该级别以上级别的反趋势。

### 4. 走势分解定理
- **分解定理一**：任何走势可分解为同级别"盘整 + 下跌 + 上涨"三种走势类型的连接。
- **分解定理二**：任何走势类型至少由三段以上次级别走势类型构成。

## 三、三类买卖点完全定义

### 1. 三类买点

| 买点 | 位置 | 几何与结构形成机制 | 安全性与特征 |
|------|------|--------------------|--------------|
| **第一类买点 (1买)** | 下跌趋势结束点 | 下跌趋势末端（通常含2个以上中枢），c段对b段产生趋势背驰 | 价格最低，但需确认背驰不发生小转大的变异 |
| **第二类买点 (2买)** | 1买后的第一次次级别回调低点 | 1买后向上次级别走势完成后的次级别回调，低点不跌破1买点（或盘背不大幅创新低） | **最安全**。大级别2买 = 次级别1买（买卖点定律一） |
| **第三类买点 (三买)** | 突破中枢后的次级别回抽低点 | 次级别离开中枢后，随后的次级别回抽低点高于中枢高点 $ZG$ | **最强主升浪追涨点**。确认中枢被破坏、趋势延续 |

### 2. 2买的三分法
1. **二三买合一（最强）**：2买回调低点刚好高于原下跌最后一个中枢的 $ZG$，构成V型反转。
2. **依次递升（标准）**：$Buy_1 < Buy_2 < Buy_3$。
3. **盘背破底（最弱）**：2买回调稍微跌破1买点，但与1买形成盘整背驰。

### 3. 三类卖点（完全对称）
- **一卖**：上涨趋势背驰点。
- **二卖**：一卖后第一次次级别反弹不创新高的节点。
- **三卖**：跌破中枢后次级别反弹高点低于中枢低点 $ZD$。
- **重合卖点**：第二类卖点与第三类卖点重合时（二卖也是前中枢三卖），下跌力度极大，必须果断清仓。

## 四、四种转折方式完全分类

| 转折方式 | 结构特征 | 判断要点 |
|----------|----------|----------|
| **标准趋势背驰转折** | $a + A + b + B + c$ 完整结构 | $c$ 段对 $b$ 段背驰，且 $c$ 内部包含次级别背驰（多级共振） |
| **非标趋势转折 (盘背转折)** | 最后一个中枢出现3买转2卖或未创新低直接转折 | 趋势中最后一个中枢前后的盘整背驰引发，需提前识别 |
| **盘整转折** | 只有一个中枢的盘整 | 比较中枢前后离开段力度，判断盘整背驰 |
| **小转大** | 本级别无背驰，次级别/次次级别背驰引发大反转 | 常出现在趋势末端加速段（冲顶或赶底），需结合区间套与底/顶分型 |

## 五、技术指标与辅助系统规则

### 1. MACD 背驰辅助判断
- **黄白线（DIF/DEA）**：反映大趋势力度。走势创新高/新低，但黄白线未创新高/新低 → 预警背驰。
- **红绿柱面积**：比较同向走势段（如 $b$ 段与 $c$ 段）对应的红/绿柱累积面积。$c$ 段面积小于 $b$ 段面积 → 背驰成立。

### 2. 均线系统（吻的分类）
- **飞吻**：短周期均线短暂靠近长周期均线后迅速离开（强趋势延续）。
- **唇吻**：短周期均线接触长周期均线后离开（次级别回调）。
- **湿吻**：短周期均线与长周期均线反复纠缠穿越（中枢形成或趋势转折）。

### 3. 布林通道 (BOLL)
- **1买/1卖**：股价跌出/冲出轨道后缩回，再次创新低/高但无法重回轨道强力区。
- **中阴期收口**：BOLL通道上下轨收口预示中阴阶段即将结束，即将产生第三类买卖点。

### 4. 中轴强弱法则
- 中枢中轴 $Z = \frac{ZG + ZD}{2}$。
- 震荡中点 $Z_n > Z$ 表示震荡偏强；$Z_n < Z$ 表示震荡偏弱；$Z_n$ 超越 $ZG$ 或 $ZD$ 为变盘预警。
