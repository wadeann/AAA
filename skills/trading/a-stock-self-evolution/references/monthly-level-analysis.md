# 月线级别分析的完整方法

## 触发条件

当用户问"大盘是否月线级别调整"、"大盘目前处于什么阶段"、"月线趋势判断"等跨周期问题时使用。

## 基本数据采集

月线分析需要比日线/周线更广的数据源。使用以下 MCP 组合拳：

### 1. 四指数月线 K 线

`mcp_intel_fetch_kline(period="1", count=360, symbol="000001.SH")` 返回的是分钟级 K 线不是日/月 K 线。
正确的月线数据获取方式：

```python
# 用 wencai 查月度数据
mcp_intel_wencai_search("上证指数 月度涨跌幅 2026年1月 2月 3月 4月 5月 6月 7月 8月")
mcp_intel_wencai_search("深证成指 月度涨跌幅 2026年1月 2月 3月 4月 5月 6月 7月 8月")
```

### 2. 月线中枢计算

月线中枢需要至少 3 根月 K 线的重叠区间。2026 年截止 8 月的月 K 线数据：
- 月线中枢 ZD（下沿）：取相邻 3 个月 K 线低点的最大值
- 月线中枢 ZG（上沿）：取相邻 3 个月 K 线高点的最小值

### 3. 其他辅助数据

```python
# 板块资金流向（TOP5/BOTTOM5）
mcp_intel_wencai_search("行业板块近5日涨幅排名 近10日涨幅排名")
mcp_intel_wencai_search("行业板块资金净流入排名 TOP5")
mcp_intel_wencai_search("行业板块资金净流出排名 BOTTOM5")

# 市场健康度（仅作交叉参考，不独立依赖）
mcp_intel_fetch_market_health({})

# 热点信号
mcp_intel_fetch_hot_signals({})

# 新闻确认（宏观面）
mcp_intel_search_news("A股")
mcp_intel_search_news("降息")  # 或美联储/汇率等宏观关键词
```

## 月线分析框架

### Step 1: 确认月线结构

- 从 wencai 获取当月及前几月的涨跌幅数据
- 判断：收阳/收阴、振幅、成交量变化
- 识别月线底分型/顶分型的构建进度

### Step 2: 确认月线中枢位置

- 月线中枢是"月线级别调整"判断的核心
- **月线级别调整 ≠ 月线收阴**
- 月线调整 = 向下脱离月线中枢后，3 根月 K 线无法回到中枢区间
- 月线震荡 = 价格在中枢上下沿之间运行，未脱离中枢

### Step 3: 判断三买/三卖区间

- 月线三买：价格向上脱离月线中枢后，回调不跌回中枢
- 月线三卖：价格向下脱离月线中枢后，反弹不回中枢
- 月线趋势票的止损止盈参考月线中枢上下沿

### Step 4: 辅助验证

- 成交额趋势（月成交额萎缩 → 底部缩量企稳）
- 板块结构（权重 vs 成长 是否分化）
- 宏观催化是否存在（降准降息/经济数据/中美关系）

## 输出格式

用表格简洁呈现，不加情绪化描述：

```
## 月线分析结论

| 维度 | 数据 | 判断 |
|------|------|------|
| 上证X月K线 | +X.XX% 收阳/阴，成交量XX亿 | 底分型构建中/已成型 |
| 月线中枢 | [ZG, ZD]区间 | 未脱离/向上脱离/向下脱离 |
| 月线级别调整 | 否/是 | 中枢震荡/三卖确认/待确认 |
| 成交额 | XX万亿（月均） | 缩量/放量/正常 |
| 板块结构 | TOP3/BOTTOM3 | 结构健康/分化 |
```

## 避免的陷阱

- **不要用 `fetch_kline(period="1")` 当日 K 线做月线分析** → period=1 是 1 分钟线
- **不要凭单月阴阳判断"月线调整"** → 月线调整必须有中枢脱离证据
- **月线数据=wencai 最佳**，MCP 原生 K 线接口不支持月线
- **不要跨市场猜宏观** → 只分析 A 股数据，港美股/汇率/商品作为补充参考
