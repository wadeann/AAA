## 二、全局铁律（22条，逐条为校验闸门）

1. **禁产出降级（最高）**：严格按模板，逐营业部全名/完整字段；⬜只用于"真调不到"。
2. **表下规则=强制校验**：每表逐条✅/⬜，全✅才输出该段。
3. **当日取数缓存**：每笔登记（数据项|工具|结果|段落），后续段直接引用，禁重复调工具。
4. **成本原则**：GVE ffd_* = 主源（免费），通达信 = 辅源（仅核验/独有数据）。
5. **结论带推理链**：数据源 → 判断标准 → 结论，禁裸结论。
6. **步骤归因各归其位**：身份确认 ≠ 能买，分开写。
7. **空数据标⬜**：禁编造任何代码/数值/言论。
8. **表格化优先**：数据一律放表格，解释用短句；关键结论加粗；每表后最多1条引用块。
9. **A股只做多**：买入/卖出/持有/观望。全中文输出。
10. **GVE历史资金流不可回溯**：当日取数必须当日落盘缓存。
11. **终检五查**（交付前强制）：①完整性 ②表头对齐 ③关键参数一致 ④缺口清零+查编造 ⑤翻译（飞书英文必译中文）。
12. **读图铁律**：收到图第一动作=读图，逐条解析填表。只有图真不存在才标"图未收到"。
13. **标⬜熔断+降级预案**：核心数据缺失>3项→熔断先修源。降级P1真实→P2官方替代→P3标⬜；禁跨时间周期平替。
14. **前提条件拦截**：IF封板数据缺失/⬜ THEN 否决关禁标"过"。
15. **模块化拼装**：写作前跑 `python build_skeleton.py {日期}` 生成底稿（53段+66表+249小字+391⬜占位），只填空禁白纸手写。
16. **选股知识溯源铁律**：⑤段选股前读知识清单；每只候选票带 `【溯源:知识文件名§章节】`。
17. **取数-写作两阶段分离+写前取数齐备门**（省token最高铁律·凌驾一切）：①纯取数落盘 ②纯写作。两阶段间设齐备门，全✅才动笔。
18. **占位符黑名单**：待实拉/待拉/待取/待查/收盘价待/待竞价/TBD/待定 = 能取没取，终检FAIL。
19. **段级关卡**：写每段前先跑 `python section_guide.py {段号}`，把 `【🔒段级关卡已加载】` 写入段首，终检㉖查。
20. **数字溯源·facts表**：取数收口=填满 `facts_{日期}.md`（copy facts_模板.md），写作只准从facts抄数字，facts没有=编造，终检⑨FAIL。
21. **正文覆盖度铁律**：facts取N条，正文展开N条关键项，禁"取10写3"。游资必展开完整惯用手法（非简称）、时间精确到HH:MM。
22. **取数阶段硬性STOP点**：手动跑复盘时，取数结束=本turn终点，输出「取数齐备报告」后立即STOP，写作由用户下一命令触发。（自动化21:30例外：facts三关全绿+空值0才准继续写作）

## 三、①段各节格式细则

### 1.1 四大指数收盘
表列：指数|前收|今收|涨跌幅|今开|今高|今低|点评
- 上证指数/深证成指/创业板指/北证50（或按当日口径）
- 今收+涨跌幅加粗，点评含量价结构（如"缩量收在下行60日线下·银行为主护盘"）
- 取数：query_data四指数（铁律：禁用fetch_market_health——东财海外封杀→缓存降级→旧数据bug）

### 1.2 量能与结构解读
- 沪深两市成交额（多源对比：GVE/通达信/用户图）
- 量能三句话：放缩量定性 + 结构解读（普跌/分化）+ 一句话结论

### 1.2.5 龙头情绪观察表 + 月线牛股
- 连板梯队：最高板→次高板，逐板龙头（名称+代码+板数+炸板情况）
- 昨涨停今表现（溢价/亏钱效应）
- 月线牛股：当月涨跌幅前列，标注驱动逻辑

### 1.3 板块资金流向表（申万二级双向·SW2021 134行业）
- 双向：流入Top N / 流出Top N，各行业净额（亿元）
- 1.3.5 板块资金全天流动图分析：用户供图逐条读图解析，流入TOP10/流出TOP10/点位
- 取数：板块资金仅当日可取（GVE不可回溯）

### 1.4.1 市场情绪温度计（三块完整结构）
主表列：温度(得分/档)|涨跌家数比|涨跌停(涨/跌/炸板率)|涨跌幅中位数|活跃度(高换手/总成交)|情绪判定|次日动作
- 情绪周期四阶段量化阈值：**冰点**（空间2-4板/连板5-10）→试探轻仓 | **试探期**（连板10-15）→主线首板优先 | **上升期**（空间破5板/连板15-40）→进核心 | **退潮**（龙头断板/炸板率骤升）→空仓
- 判定=空间龙头高度+连板梯队+炸板率+昨涨停今表现
- 取数：market_sentiment market_temperature 主→GVE备

### 1.4.2 龙虎榜席位分析
- 逐营业部全名拆解（机构专用/知名游资/量化席位）
- 净买入/净卖出方向、金额、对应个股

### 1.4.3 跨市场联动表
- 港股/美股/期货/汇率/商品（铜/锂/硅）联动及对A股的传导

### 1.5 大盘趋势阶段判定
- 均线多空排列（5/10/20/60日线）+量价结构 → 阶段定性（上升/震荡/下降）

### 1.6.5 上证指数 5分钟缠论三剧本
- 三剧本：强势/震荡/弱势，各剧本触发条件+对应仓位+操作预案
- 缠论结构：笔→中枢→背驰，价格是结果，结构是条件

### 1.6 观察锚点（次日）
- 关键位（支撑/压力）、开盘15分钟定式、板块轮动节奏、消息面要点

### 1.7 事件/公告归因
- **1.7.1 盘中新闻轴**：按时间线（HH:MM精确）列盘中要闻
- **1.7.2 公司公告+事件**：逐条（回购/减持/质押/业绩/授权），标注正负面
- **1.7.3 全球背景**：盘后15:00→复盘时的海外市场/宏观事件
- **1.7.4 研报归因**：当日研报方向提炼，取N条展开N条
- **1.7.5 宏观事件日历**：当日/近7日财经日历
- **1.7.5.2 宏观因子红绿灯矩阵**：各宏观因子红/黄/绿+仓位基准（凌驾一切的总开关）
- **1.7.6 归因小结**：8子项全必填（主攻方向/禁打板判据/退潮判据/资金方向/资金撤离/情绪反向/公告正负/排雷）

### 1.7.7 ①段→⑤段选股素材卡（18项强制桥梁）
表列：#|素材项|①段来源|①段取值(实际数据)|⑤段消费动作(第1-5步必须出现)|已消费✅
- 18项：主攻方向/禁打板判据/退潮冰点判据/资金最坚决方向/资金撤离/情绪反向/公告正/排雷/全球/冷门/可持续/题材级别/宏观闸门/主导风格/龙虎榜出货预警/主线四状态/板块资金Top/温度拥挤度
- 铁律：①段取实数据→⑤段必须消费；⑤段全文未出现处理动作→FAIL（机器校验㉓查）

```
  [7] 盘中新闻轴/公告/全球/研报/宏观日历 → facts
  [8] 缠论三剧本（30/60分K线）→ facts
  [9] 填满 facts_{日期}.md + check_facts 三关全绿
  [10] 输出取数齐备报告 → 手动模式STOP
阶段2 写作：
  [1] python build_skeleton.py {日期} 生成53段底稿
  [2] 每段前 python section_guide.py {段号} 加载段级关卡
  [3] 从facts抄数字填空，禁边写边取
  [4] 18项素材卡逐项映射到⑤段消费动作（本模板只到①段，⑤段为延伸）
  [5] 终检 check_review_alignment.py 五查+机器校验全绿
```

## 六、铁律速记（凌驾一切的顶层红线）

1. **禁编造数字** — facts表没有的数字=编造=FIN
2. **禁产出降级** — ⬜只能用于"真调不到"，禁用于"懒得做"
3. **两阶段分离** — 取数完→STOP→等命令再写正文
4. **读图铁律** — 用户给的图必须读，禁跳填⬜
5. **数字可视化优先** — 表格化+加粗关键结论
