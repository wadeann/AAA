# 缠论选股与扫描器 (Chan Theory Stock Screener)

本 Skill 专门用于市场机会扫描与选股。通过"自上而下三步法"、"主力资金模式"与"牛市选股法"筛选高质量标的。

> 理论引用：查看 [`chanlun-theory`](skill:chanlun-theory) 了解基础定义。

---

## 一、触发条件
当用户要求"选股"、"寻找买点标的"、"推荐股票"、"扫描市场机会"或"分析板块轮动"时使用。

---

```json
}
```

## 三、核心选股战法体系

### 0. 🔴 板块趋势识别（P0 — 最高优先级，每次扫描必须执行）

**这是系统的眼睛。板块跑了8天都不知道 = 系统性失明。**

#### 数据源优先级与容灾

| 优先级 | 数据源 | 适用场景 | 限制 |
|--------|--------|----------|------|
| P0 | `mcp_intel_wencai_search` | 结构化板块/资金/涨停查询 | 每日限额(401:次数用完) |
| P1 | `mcp_intel_webx_search` + 聚合站 | wencai不可用时的替代 | 需解析非结构化页面 |
| P2 | `mcp_intel_fetch_market_health()` | 大盘温度+总流向 | 板块级粒度不足 |
| P3 | 预跑脚本(Antigravity/板块资金流向) | 已准备好的每日板块摘要 | 非自主可控 |

**容灾策略**：当 wencai 返回 401/次数用完时，不要停止。改用 P1+P2+P3 组合继续输出。

**P1 聚合站推荐**（wencai不可用时抓取）：
- `https://hhxg.top/` — 题材热点、连板天梯、赚钱效应、行业板块资金（按申万）、ETF风向、游资龙虎榜、共振信号。关键词：涨停家数、连板最高板数、封板率、炸板数、前5大热门题材
- `https://lianban.net/` — 涨停板块归属、连板梯队、主线题材汇总
- `https://data.eastmoney.com/bkzj/` — 东方财富行业板块资金流向
- `https://fundflow.fanglongfinance.com/` — 主力资金净流入/净流出排行

抓取方法：`curl -sL --max-time 10 URL | grep -oP ...` 或 `browser_navigate` 获取页面内容。hhxg.top 页面HTML中嵌入完整的连板数据（涨停家数、连板家数、最高板、跌停、封板率、炸板）以及题材热点标签。

**A. 板块涨幅持续天数扫描**
- **首选 (wencai可用)**：`mcp_intel_wencai_search("近5日涨幅最大的行业板块")` + `mcp_intel_wencai_search("近10日涨幅最大的行业板块")`
- **容灾 (wencai不可用)**：`mcp_intel_webx_search("2026-MM-DD A股 涨停 板块 资金流向")` 或加载 hhxg.top 页面提取题材热点标签
- 交叉对比：5日榜和10日榜同时出现的板块 → 🔥持续主线
- 追踪板块内连板梯队（≥3连板的个股数量）
- 输出格式：
  ```
  🔥 持续主线：[板块名] 连续X日走强 | 连板梯队：N板(股数) N-1板(股数) ...
  ⚡ 新晋板块：[板块名] 今日首次进入TOP5 | 催化剂：XXX
  ```

**B. 板块资金流入趋势扫描**
- **首选**：`mcp_intel_wencai_search("今日主力资金净流入最大的行业板块")`
- **容灾**：`mcp_intel_webx_search` 搜索"2026-MM-DD 主力资金净流入板块 申万行业" 或 加载东方财富/同花顺板块资金页面获取TOP5流入/流出板块
- 全市场总流向：`mcp_intel_fetch_market_health()` 返回的 `total_flow_billion`（注意：该接口返回的是昨日/延迟数据）
- 与昨日板块资金记录对比（参考 `~/.hermes/trading/sector_flow_history.md`）
- 连续3日净流入板块 → 🔥标记

**C. 涨停板板块归属统计**
- **首选**：wencai 查"今日涨停 非ST"
- **容灾**：通过 `mcp_intel_webx_search` 搜索 "2026-MM-DD 涨停 连板 涨停家数" 获取聚合站数据。hhxg.top 页面通常嵌入 `<meta>` 信息或页面文本包含涨停/连板/跌停数量
- 按板块归类，统计每个板块涨停家数
- ≥5家涨停的板块 → 🔴必须深入分析
- 识别连板龙头（最高板数、封单强度、换手率）

**D. 板块催化剂溯源（不可跳过）**
- **首选**：对每个 🔥板块，wencai 搜索"{板块名} 利好消息 政策"
- **容灾**：`mcp_intel_webx_search("{板块名} 2026-MM-DD 政策 利好")` + `mcp_intel_search_news(symbol=板块龙头代码)`
- 识别催化剂类型：政策/业绩/产品/事件/超跌反弹
- 超跌反弹型 → 不追；政策+业绩双驱动 → 最高优先级

**以上四步是所有选股的前置条件。先看板块，再看个股。**

#### ⚠️ P0 独立调用模式

P0（板块趋势识别）可被 **单独调用**，例如：
- 板块资金流向 cron（仅需板块趋势+资金流向分析）
- 收盘复盘的板块部分（不涉及个股筛选）
- 日常问股中"今天什么板块最强"

**P0独立调用时**，仅输出板块趋势识别结果，无需执行：
- ❌ 写入 alert_plan（候选池未建立）
- ❌ 加入 watchlist（无个股候选）
- ❌ 计算持仓三件套（个股分析未涉及）
- ❌ 构建 candidate_pool JSON

**P0+P1+P2+P3+P4+P5完整调用时**，须执行全部选股后落地动作（见第五部分）。

### 1. 系统化"自上而下"三步选股法
1. **政策与产业定方向**：依据国家政策与产业景气度筛选 5~7 个重点行业板块。
2. **板块指数择时**：拆解板块指数中枢结构，锁定出现/即将出现大级别（日线/30分钟）买点的板块。
3. **个股筛选建池**：在目标板块中剔除暴雷、解禁风险标的，挑选交易活跃、强于板块的股票，锁定 <50 只股票入池。

### 2. 牛市选股三法
- **强势股插档**：在回调时跟进强势股（牛市"跌就是爹"）。
- **新股突破法**：放量突破上市首日最高价的新股。
- **年线突破法**：放量突破年线（250日线）后缩量回调年线（**最可靠牛股形态**）。

### 3. 主力资金驱动选股
- **模式A：短线主升浪（热点+游资）**
  - 特征：涨停板/放量大阳/封单过亿，龙虎榜有知名游资/机构。
  - 买点：等待次级别回调买点（如5分2买/1分1买）介入。
- **模式B：大级别趋势长牛（龙头+机构资金）**
  - 特征：连续3年扣非净利润增速 > 30%，EPS > 0.5元，PE < 40~50倍。
  - 买点：回调至 20周均线 附近建仓/加仓。

### 4. 黄金高胜率买点组合
- ✅ `周线2买 + 日线2买共振`
- ✅ `日线2买 + 30分2买共振`
- ✅ `30分2买 + 5分1买`
- ✅ `5分2买 + 1分1买`
- ❌ **禁忌组合**：`30分2卖 + 5分1买`（大级别向下未衰竭，小级别买点属于刀口舔血）

### 5. 选股禁区（自动过滤）
- ❌ 严禁参与 ST 股、退市风险股、小盘绩差股。
- ❌ 严禁参与高控盘庄股（资金链易断裂）。
- ❌ 严禁参与高位抱团股补跌段。
- ❌ 均线空排或股价长期在年线下方运行的股票。
- ❌ 无活力的 ED 股（成交量持续萎缩）。

## 五、选股后落地动作（必须在输出候选池后执行，2026-08 教训）

**用户期望：选股不只是给清单，选出的重点标的必须进入持续跟踪，下次开盘自动盯。**

候选池输出后，对 strength_rating ≥ A 的标的下，立即执行：

### 1. 写入 alert_plan（重点观察列表）
- 位置：`~/.hermes/trading/alert_plans/alert_plan_YYYY-MM-DD.json`
- 为每只强度≥A的候选写入 `{code, name, watch_price, add_price, stop_loss, note}`
- 下次开盘 cron（open 扫描 / orchestrator）会读取此文件自动跟踪
- 若不写入 alert_plan，候选只是"纸面名单"，不满足用户对"重点观察列表"的期待

### 2. 加入 watchlist（自选股）
- `mcp_intel_update_watchlist(action="add", symbol, name, reason="筛选原因")`

### 3. 持仓分析必须立即算三件套（2026-08-15 教训）
用户问"加仓信号/止盈信号你计算了吗"——**一旦分析或跟踪某只持仓股，下一步必须立即计算并输出加仓/止盈/止损三件套**，不要只设保护位或只给方向，等用户追问。三件套逻辑见 `a-stock-operation-guide`（缠论结构条件，非固定点位）。

### 4. 完整性检查
落地完成后自查：候选是否已进 alert_plan？已进 watchlist？持仓的三件套是否已给出？缺失任一 = 流程不完整，需补齐。
