# 自选股批量扫描工作流参考

## 场景
用户要求分析全部自选股（17只+），给出缠论操作指导，记录文档用于下周跟踪。

## 工作流步骤

### 1. 加载技能
必须先加载：`chanlun-theory` + `chanlun-analyzer` + `a-stock-operation-guide`

### 2. 拉大盘数据
`mcp_intel_query_data` 四指数（000001.SH, 399006.SZ, 399001.SZ, 000688.SH）

### 3. 批量拉行情
`mcp_intel_query_batch_data` 分两批（每批最多10只），避免单次请求过大

### 4. 并行缠论分析（关键模式）
用 `delegate_task` 分3个子任务，每组5-6只股票：
- 每个子任务独立调用 `mcp_intel_fetch_kline(symbol, period="30", count=100)` 拉100根K线
- 按缠论十步流程分析：包含处理→分型→笔→线段→中枢→背驰→买卖点
- 输出格式统一：【代码 名称 现价 涨幅】+ 走势类型 + 中枢 + 背驰 + 买卖点 + 操作 + 关键位

### 5. 汇总写入文档
- 汇总所有子任务结果到一张表
- 操作分类：BUY / HOLD / 观望
- 写入 `~/.hermes/trading/watchlist_chanlun_YYYYMMDD.md`
- ⚠️ 用户可能要求完整输出到对话框，准备好直接发送全文

### 6. 关键约束
- 每只必须拉100根K线（不漏浪型全貌）
- 先定性（趋势/盘整/下跌反弹）再谈具体点位
- 量价不分离
- 敢于标❌说不碰
- 行业集中度40%硬限提示

## 上下文传递要点
子任务需要被告知：
- 大盘环境（四指数现价+涨幅）
- 每只股票的当前现价+涨幅（用于快速定位K线范围）
- 统一输出格式要求
