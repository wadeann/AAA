# 缠论中枢可审计说明

适用于用户追问“中枢怎么确定”“为什么这里算中枢”，或报告将突破/回抽归类为三买、三卖时。

## 1. 必须先披露计算口径

区分两种口径，不得混称：

- **严格缠论中枢**：连续三个次级别走势类型的重叠区。
- **量化代理中枢**：程序以包含处理后的连续三笔重叠作为可审计近似。

若使用 `chanlun_engine.py`，必须明确称为“三笔重叠代理中枢”；不能直接声称已完成严格次级别走势中枢。实战结论还需检查笔是否扩展为完整次级别走势类型。

## 2. 固定重建流程

1. 锁定分析级别与100根K线数据边界，例如30分钟、最后K线时间。
2. 顺序执行：K线包含处理 → 顶底分型 → 笔 → 线段/次级别走势 → 中枢。
3. 列出构成目标中枢的三段端点、方向、起止时间和价格区间。
4. 计算：
   - `ZD = max(d1, d2, d3)`
   - `ZG = min(g1, g2, g3)`
   - 仅当 `ZD < ZG` 时中枢成立，区间为 `[ZD, ZG]`
   - 中轴 `Z = (ZD + ZG) / 2`
5. 相邻滑窗生成大量重叠中枢时，应合并解释为同一中枢的延伸/震荡收窄，不能把每个三笔滑窗都当成独立新中枢。
6. 选择“当前有效中枢”时，优先使用最近一个能够解释离开段与回抽段的稳定重叠区，并说明为什么不是更早或更窄的内部重叠区。

## 3. 三买/三卖确认

- **三买**：次级别向上离开中枢后，随后的完整次级别回抽低点严格高于 `ZG`。
- **三卖**：次级别向下离开中枢后，随后的完整次级别反抽高点严格低于 `ZD`。
- 只有离开、尚无完整回抽时，称“突破/三买候选”，不得提前写“三买成立”。
- 回抽尚未形成确认分型或次级别走势未完成时，称“初步结构”，并写明缺少的确认步骤。

## 4. 对话输出模板

```text
口径：30分钟三笔重叠代理中枢（严格中枢仍需次级别走势确认）。
构成三笔：
1. 下：A → B，区间[d1,g1]
2. 上：B → C，区间[d2,g2]
3. 下：C → D，区间[d3,g3]
ZD=max(...)=X；ZG=min(...)=Y；所以中枢=[X,Y]，中轴=Z。
当前状态：已离开/正在回抽/回抽不入已确认；对应三买候选/三买成立。
```

## 5. 常见错误

- 肉眼把横盘箱体直接叫中枢，却不给分型、笔和重叠计算。
- 输出一个区间但不说明由哪三段构成。
- 把程序“三笔代理中枢”冒充严格缠论中枢。
- 把中枢延伸中的窄重叠区误判为全新的独立中枢。
- 价格刚越过 `ZG` 就宣布三买，遗漏“完整回抽不入中枢”。
- 不披露K线级别、数据截止时间，导致不同级别中枢混用。
