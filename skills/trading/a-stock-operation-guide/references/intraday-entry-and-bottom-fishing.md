# 盘中买入价格与“能否抄底”判定

适用场景：用户明确问“买入价格/什么价买/可以抄底了吗”。这是个股操作指导的盘中执行分支。

## 一、最低数据集

必须同步获取并交叉核验：

1. 实时行情双源：现价、开高低、分时均价、时间戳、五档；关键价格不一致时以权威直连源为准。
2. 5分钟、30分钟、日线K线：至少识别当日分时结构、30分钟中枢/趋势及日线压力。
3. 主力资金：当日、5/10/20日净额；超大单与龙虎榜/机构席位单列。
4. 筹码与技术：平均成本、获利盘、MA、MACD、RSI、BOLL。
5. 财务与新闻：排查公告、减持、质押、可转债、业绩及突发利空。新闻搜索结果若明显错配，不得作为个股依据。

## 二、买卖价格必须明确

面向用户的最终报告必须给出可以直接挂单执行的具体价格：

1. **第一买价**：明确到具体价格或不超过0.5%的窄幅区间。
2. **第二买价/加仓价**：明确价格，并写明计划仓位。
3. **减仓价**：明确到价卖出多少仓位。
4. **清仓价/止损价**：明确无条件执行价格。

内部分析可以参考分时均价、筹码成本、前高低点和30分钟结构，但最终输出不得只写“底分型、中枢、背驰、三买、三卖、收复均价”等术语，必须全部翻译成“价格 + 动作 + 仓位”。

## 三、“可以抄底了吗”四道门

只有四门全部通过，才可回答“可以小仓试错”；否则回答“不能抄，等右侧确认”。

### 门1：下跌停止
- 5分钟不再创新低；
- 出现有效底分型；
- 后一笔上行突破前一段下跌结构。

### 门2：价格收复
- 重新站上分时均价；
- 最好同时收复筹码平均成本或关键中枢边界；
- 仅从低点反弹但仍压在均价/成本下，定性为弱反抽。

### 门3：资金止血
- 当日主力与超大单流出明显收敛或转正；
- 龙虎榜净卖出、机构/深股通集中卖出时，不因单一技术超卖抄底；
- 小单净流入不能替代主力承接。

### 门4：结构未破坏
- 前期启动位、涨停启动结构或30分钟中枢不能被放量跌破；
- 跌破后反抽不回属于三卖，禁止越跌越买；
- 新股、次新股、小流通盘、高换手标的自动降低仓位。

## 四、特殊情形

### 涨停后回落
涨停后1—3日的下跌优先视为获利兑现，不因跌幅变大自动定义为“底”。重点检查：30分钟MA5/10/20、涨停启动结构、龙虎榜净买卖和当日主力流向。

### 盘中高位回落
若当日曾明显冲高，距高点回撤扩大且跌破分时均价，不在下落过程中接；等底分型和均价收复。

### 次新股
上市时间短、筹码历史不足时，降低筹码指标权重，提高换手率、龙虎榜和分时承接权重；试错仓通常不超过3%—5%。

## 五、极简输出模板

```text
分析来源：Hermes 当前主模型
依据(≤3行):
* 【事实】实时位置与5/30分钟结构。
* 【事实】主力/龙虎榜与筹码成本。
* 【推断】抄底门是否通过。
打法(≤3条，具名):
1. 当前是否执行。
2. 允许试仓的结构条件（可附条件化价格区间）。
3. 放弃条件。
红线:
结构破坏条件；单票仓位上限。
```

## 六、常见错误

- 只因RSI低、跌幅大或接近均线就称“可以抄底”。
- 给出裸价格，不写底分型、均价收复、资金止血等触发条件。
- 把小单承接当成主力回流。
- 新闻检索错配到同代码片段或无关行业，仍拿来论证。
- 忽略涨停后兑现、龙虎榜净卖出和次新股高换手风险。
