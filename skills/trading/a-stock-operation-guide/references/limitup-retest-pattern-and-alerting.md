# 涨停回踩中期均线：形态判定与监控接入

## 适用场景

用户询问“涨停后回落到50/60日线再上涨，是否洗盘”“多只股票是否属于同一形态”，或要求把该类标的加入观察并在买点出现时提示。

## 形态名称

常见称谓：
- 涨停回马枪
- 突破—回踩—再突破
- N字二波
- 深度换手后的二次启动

这些名称只能描述候选形态，不能仅凭“出现过涨停 + 触及MA50/MA60”断言主力已完成洗盘。洗盘只能在重新突破后事后确认。

## 六维判定矩阵

按以下顺序核验：

1. **启动强度**：存在放量涨停或接近涨停的有效突破，且不是下降趋势中的孤立脉冲。
2. **回踩位置**：回踩MA50/MA60、涨停启动平台或前期箱体上沿；多个支撑重合优于单一均线。
3. **回调量能**：回调总体缩量；持续放量下跌更接近派发。
4. **成本与均线修复**：反弹至少收复筹码平均成本、MA5/MA10及MA20；仅在MA60附近反弹不算完成。
5. **资金验证**：当日回流不够，优先要求5日主力净额止血或转正；龙虎榜净卖出时降低评级。
6. **二次突破**：放量突破涨停后的回调平台或阶段前高，才正式确认“N字右侧”。

## 三级分类

### A级：标准回马枪

同时满足：
- 回踩关键支撑后止跌；
- 当前价已收复筹码成本和多数短期均线；
- 5/10/20日资金至少不再持续恶化；
- 距阶段前高较近，具备明确突破触发位。

操作：只在放量突破阶段前高时触发复核，不提前追涨。

### B级：回马枪候选

通常表现为：
- 回踩位置标准；
- 但尚未收复筹码成本、MA10/MA20，或5日资金仍明显流出。

操作：先等成本区和短期均线修复，再观察前高突破。

### C级：弱反抽/暂不成立

满足任一：
- 当前价仍在MA60及筹码成本下方；
- 回调放量、获利盘低且上方套牢密集；
- 5日资金显著净流出或龙虎榜净卖出；
- 反弹无法收复回调平台。

操作：不按洗盘处理，暂不纳入突破买点。

## 多股横评输出

必须给唯一排序，并逐票写清：
- 最近一次有效涨停日期及涨停价/阶段高点；
- 回踩低点与MA50/MA60位置；
- 当前价相对MA5/10/20/60和筹码成本的位置；
- 当日、5日、10日、20日主力净额；
- 确认价与失效价；
- 评级：标准 / 候选 / 不成立。

避免把所有股票都笼统称为“同一种形态”。外形相似不代表资金质量和完成度相同。

## “加入观察，有买点提示”执行闭环

不能只更新普通自选股。必须完成两层接入：

1. **自选股层**：调用 `update_watchlist`，reason写明形态、突破触发位和关键成本支撑。
2. **盘中警戒层**：写入当日 `trading/alert_plans/alert_plan_YYYY-MM-DD.json`，由已有 `intraday-leader-monitor` 统一扫描，禁止为单票新建cron。

买入警戒建议字段：

```json
{
  "symbol": "600000.SH",
  "name": "示例股票",
  "direction": "buy",
  "position_class": "swing",
  "thesis": "涨停回马枪候选，等待前高突破确认",
  "entry_rule": "放量突破阶段前高后触发复核；需确认分时承接、资金回流和无重大利空",
  "buy_alert": {
    "above": 8.42,
    "reason": "突破阶段前高，触发二波买点复核"
  },
  "exit_rule": {
    "type": "structure",
    "stop_loss_structural": 7.70,
    "cancel_signals": [
      "跌破筹码成本区",
      "跌破回踩低点",
      "突破后放量回落"
    ]
  },
  "leader_class": "limitup_retest",
  "catalyst_type": "technical_breakout"
}
```

## 触发不等于直接买入

警戒价命中后必须复核：
- 突破量能是否有效；
- 分时是否站稳触发价而非瞬时上影；
- 主力资金是否继续流入；
- 板块是否共振；
- 是否存在公告或新闻利空。

无量假突破、冲高快速跌回触发价下方，不生成买入结论。

## 验证

写入后至少验证：
- JSON可解析；
- `symbol`、`direction=buy`、`buy_alert.above`、结构取消位均正确；
- 实际运行统一监控脚本无异常退出；
- 用户收到的是明确的触发价、取消条件和监控状态，而不是“已关注”的空泛回复。
