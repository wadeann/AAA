# 海外 IP 实时行情延迟

## 发现日期
2026-06-19

## 问题描述
服务器位于 Oracle Cloud 海外节点（Linux 6.8.0-1054-oracle），所有 A 股实时行情数据源对海外 IP 做了延迟处理，盘中只能获取上一交易日收盘数据。

## 实测结果

### 腾讯行情 API（qt.gtimg.cn）
```
上证指数: 当前=4090.48 昨收=4108.08 涨跌幅=-0.43% 时间=20260618161419
深证成指: 当前=16030.70 昨收=15880.95 涨跌幅=0.94% 时间=20260618161445
```
→ 时间戳为昨日收盘，今日盘中不更新

### 新浪行情 API（hq.sinajs.cn）
```
上证指数,4094.2301,4108.0762,4090.4813,...,2026-06-18,15:30:39
```
→ 日期为 2026-06-18，今日盘中不更新

### 东方财富 push2 API
```
HTTP Error 502: Bad Gateway
```
→ 海外 IP 直接拒绝

### akshare Python 库
```
ConnectionError: ('Connection aborted.', RemoteDisconnected('Remote end closed connection without response'))
```
→ 海外 IP 被封

### wencai_search
返回数据列名为 `收盘价[20260618]`、`涨跌幅[20260618]`——均为昨日数据，无盘中实时数据

### mcp_intel_fetch_market_health
返回 `summary: "资金震荡盘整 (数据延迟-数据源同步中)"`——自身标注延迟

## 影响范围

| 能力 | 状态 | 替代方案 |
|------|------|---------|
| 昨日收盘行情 | ✅ 可用 | 直接使用 |
| 板块资金流向（昨日） | ✅ 可用 | 用于趋势预判 |
| 涨停股列表（昨日） | ✅ 可用 | 次日轮动预判 |
| 持仓盈亏（基于昨日收盘） | ✅ 可用 | 成本+昨日收盘价计算 |
| 今日盘中实时涨跌 | ❌ 不可用 | 需用户告知或配代理 |
| 今日板块异动 | ❌ 不可用 | 需用户告知 |
| 今日竞价数据 | ❌ 不可用 | 无法获取 |
| 分钟级 K 线 | ❌ 不可用 | 东财 K 线 API 也被封 |

## 缓解方案

### 短期（当前可用）
1. **用户告知盘中方向**：用户说"上证绿的"→ 以此为大盘方向判断
2. **基于昨日数据做预判**：板块资金流向 + 涨停股列表 → 次日大概率方向
3. **持仓基于成本做风控**：止损线基于成本价设定，不依赖实时价格

### 中期（需配置）
1. 配置境内 HTTP 代理（Socks5/HTTP Proxy）
2. 在 MCP 服务的 `.env` 中设置 `HTTP_PROXY` / `HTTPS_PROXY`

### 长期（需架构调整）
1. 将 MCP 服务迁移至境内云服务器
2. 使用券商行情推送 API（WebSocket）
3. 搭建境内代理中转服务器

## 自主交易模式注意事项

当用户要求"自主交易、自负盈亏、不需确认"时：
- **必须告知数据延迟限制**：首次启动自主交易模式时，应声明"实时行情数据延迟 1 天"
- **基于昨日数据做决策**：不做盘中追涨杀跌，只做隔日预判型交易
- **止损改用成本价百分比**：不依赖实时价格触发止损，改用"持仓浮亏超 X% 时操作"（基于最新可用数据）
- **不盲做**：如果昨日数据和用户告知的今日方向矛盾，以用户告知为准
