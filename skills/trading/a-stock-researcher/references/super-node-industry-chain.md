# 超节点（Super Node）产业链深度解析

> 来源：2026-07-23 用户发起超节点HBD架构分析 + 锐捷/紫光/浪潮走势对比

## 定义与架构

超节点（Super Node / High Bandwidth Domain, HBD）是数据中心网络架构升级的核心概念：将多个计算节点通过高速互联组成一个逻辑域，内部用 Scale-Up 交换 + OCS（光路交换）实现极高带宽/低延迟，外部通过 Scale-Out 分组网络连接其他超节点。

### 五层架构（从用户架构图提取）

```
Layer 5: Scale-Out 分组网络（以太网交换机，锐捷/华为/新华三）
Layer 4: 跨节点 OCS 光路交换（光路开关，锐捷核心产品）
Layer 3: 专用互联（NVLink/NVSwitch, UALink, 华为 X-Mesh）
Layer 2: Scale-Up 交换芯片（博通 Tomahawk6, 英伟达 NVSwitch）
Layer 1: 计算 Tray（GPU/CPU 节点，浪潮/新华三等集成商）
```

## 关键区别：锐捷 vs 紫光 vs 浪潮

**用户核心问题**："他们都是超节点光交换机的趋势吗？"

- **锐捷网络**：超节点概念最纯血统标的，直接做 OCS 光交换机 + 数据中心交换机。但短期乖离大（2026-07-23 周涨32%），需等10日均线回调
- **紫光股份**：新华三母公司，定位集成商，不直接做光交换机。高位放量长阴=危险信号
- **浪潮信息**：AI服务器/计算节点，不属于"光交换机"概念。中信定义为"超节点龙头"实为计算层龙头，非交换层

**结论**：三者不等同于"光交换机"，只有锐捷是光交换机正宗标的。

## 催化剂追踪

1. **华为/阿里发布超节点产品** → 锐捷/中际旭创受益
