- **注资金额**（对应资本充足率提升空间）

### Step 5：Tier 分层输出

**🔴 Tier 1：核心直接受益**
- 注资对象本身（如工商银行、农业银行 — 定增进账）
- 确定性溢价，但注意巨额定增有短期 EPS 稀释压力

**🟡 Tier 2：情绪传导受益**
- 同板块容量中军（如招商银行被银行板块情绪带动）
- 同板块龙头资金虹吸（如中国平安保险板块龙头）
- 需要严格过滤技术超买

**🟢 衍生逻辑**
- 注资后险资加仓 A 股通道打开 → 高股息/大金融标的
- 核心一级资本充足提升 → 信贷投放能力增强 → 盈利预期改善

```
| RSI(6) | 安全区 | 过热 | 偏高 |
| CCI | 温和 | 高位 | 高位 |
| 注资直接受益: | ✅ 直接 | ❌ 间接 | ❌ 情绪 |
```

## 关键判断原则

1. **注资金额最大 ≠涨幅最大**：1600亿增发的 EPS 稀释效应会让机构短期观望
2. **跟风标的严格过滤技术超买**：保险注资情绪带动的跟涨标的主力资金往往在出货（利好兑现）
3. **切忌追已连续大涨数天的核心受益股**：走势在消息公告前已包含预期，公告日=利好出尽
4. **盘面第一**：板块涨的不一定是最好的，要好+没有过热 + 没有资金反向
5. 定增发行价锚定效应：定增价溢价/平价/折价发行是短期方向的指南针
