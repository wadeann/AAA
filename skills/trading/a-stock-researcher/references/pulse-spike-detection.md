# 盘中脉冲拉升定性分析

## 场景

盘中出现单根30m/60m K线突然放巨量拉升但不封板。需要区分是"主升浪启动"还是"主力试盘/量化跟风脉冲"。

## 判断标准

### ❌ 脉冲假突破（大概率回落，不追）

1. **单根K线消耗量能占比过高**：单根30m K线成交量或成交额占全天已成交的60%以上 → 多头弹药一次性打光，后续无力封板
2. **拉升幅度不足**：脉冲拉至+5%~+7%区间遇阻回落，未触及涨停吸引区间（+8%~+10%）→ 上方抛压大，无封板意愿
3. **无突发利好催化**：消息面搜索无公告/新闻/板块联动催化 → 纯量化或游资跟风点火
4. **板块非龙头**：该板块已有明确3~4板龙头，该股是后排跟风 → 资金只会聚焦龙头
5. **长上影**：冲高回落留下明显上影线 → 上方套牢盘+获利盘双重抛压
6. **基本面疲弱**：半年报营收/净利双降、无新故事 → 缺乏持续锁仓逻辑

### ✅ 真突破（可追或等待回踩确认）

1. **量能均匀分布**：多根K线持续放量，非单根脉冲 → 资金持续流入
2. **拉升至+8%~涨停**：资金愿意扫到涨停位置 → 真封板意愿
3. **板块龙头地位**：该股是板块内最先涨停/涨幅最高的 → 资金认可
4. **有明确催化**：业绩公告、订单、政策利好等
5. **筹码结构健康**：前期充分横盘整理后突破，非低位突然偷袭

## 案例参考

### 信邦制药（002390.SZ）2026-08-28
- 30m单根K线成交9432万，占全天82% → ❌ 量能过度集中
- 拉到3.29（+6.1%）回落至3.22 → ❌ 距离涨停10%差很远
- 无突发利好，中药板块有4板龙头冀衡 → ❌ 纯跟风
- 半年报营收-13%，净利-7% → ❌ 基本面疲弱
- **结论**：量化脉冲试盘，不可能封板

## 操作规则

- 脉冲不封板 → **坚决不追**，持仓者反抽脉冲高点减仓
- 等待30m级别回踩中枢企稳（底分型确认）后再考虑介入
- 做医药投机只做板块龙头（冀衡/千金）的首板或1进2，不做后排跟风脉冲
