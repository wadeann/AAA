## 关键教训

1. **sector_history API 不可用**: 对CPO/PCB/机器人等板块码均返回error，必须用wencai替代
2. **延续性三维度**: 涨停数量 + 龙头K线 + 资金流向，缺一不可
3. **买点必须有K线依据**: 没有fetch_kline数据不能给价位建议
4. **创业板风险**: 20%涨停股震幅大，需谨慎
5. **大盘矛盾**: 大盘流出+中小盘暴涨 = 游资炒题材，需控制仓位

## 工具调用清单

**必须调用**:
1. `mcp_intel_wencai_search` — 涨停分布统计

3. `mcp_intel_wencai_search` — 龙头筛选（概念+市值+涨停）
4. `mcp_intel_query_batch_data` — 批量实时行情

- `mcp_intel_fetch_sector_history` — API已损坏
