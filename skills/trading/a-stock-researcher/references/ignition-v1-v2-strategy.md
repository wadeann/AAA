# Ignition-V1 V2 首板起爆策略（2026-09-09 升级版）

## V2 vs V1 核心变更

| 维度 | V1（旧） | V2（新） |
|------|---------|---------|
| 问财批次 | 1批（标准条件） | 4批（标准条件+放量突破+板后调整+活跃异动） |
| 去重前候选 | ~46只 | ~300~500只 |
| 精评后保留 | Top 50 | Top 150 |
| 竞价评分满分 | 20分 | 35分（含奖励分） |
| 竞价爆量比 | ❌无 | ✅竞价量/T-1总量 |
| 竞价换手率 | ❌无 | ✅竞价额/流通市值 |
| 板块热度 | 计数（同板块几只高开） | ✅加权均价（板块内所有候选竞价涨幅均值） |
| T+1退出 | ❌无 | ✅止盈半仓(+5%)/止损全清(-3%)/涨停持有 |
| 仓位记录 | ❌无 | ✅ACTIVE_POSITIONS_FILE |

## V2评分明细

### T-1盘后分（80分满分，不变）
维度同V1：涨幅分10+趋势分15+距离分20+放量分15+活跃分10+流动性分10

### T日09:25竞价分（35分满分，升级）
| 维度 | 满分 | 判定 |
|------|:----:|------|
| 竞价涨幅 | 12 | 1.8%~4.2%最佳，1.5%~5.0%次之 |
| 竞价爆量比 | 10 | 竞价成交量/T-1成交量×100%，≥5%得10分 |
| 竞价换手率 | 8 | 竞价成交额/流通市值，≥0.3%得8分 |
| 联动分 | 5 | T-1小涨+竞价大幅高开=加速；T-1跌+竞价高开=弱转强 |
| 板块热度(奖励) | +5 | 板块内所有候选竞价涨幅加权均值，≥2.5加5分 |

### 最终买入条件
1. 盘后≥65% 且 竞价≥14分 → 买入 ✅
2. 盘后≥80% + 板块热度≥2.0 + 竞价≥12分 → 买入 ✅
3. 一字板(开≥9%) → 买不进，只记录观察 ❌

### T+1退出规则
| 条件 | 操作 |
|------|------|
| 收盘≥+9%（涨停） | 持有 |
| 收盘≥+5% 且 <+9% | 半仓止盈（落袋一半） |
| 收盘≤-3% | 全清止损 |
| 其他（-3%~+5%） | 持有到次日 |

## CLI用法
```bash
# T-1 15:30盘后扫描
python3 ~/.hermes/scripts/ignition_v1_sniper.py --mode postmarket --verbose

# T 09:25竞价确认
python3 ~/.hermes/scripts/ignition_v1_sniper.py --mode auction --verbose

# T+1 14:50退出检查
python3 ~/.hermes/scripts/ignition_v1_sniper.py --mode exit --verbose

# 历史回测
python3 ~/.hermes/scripts/backtest_ignition_v1.py
```

## 数据文件
- `~/.hermes/trading/ignition_v1/candidates.json` — 盘后候选池
- `~/.hermes/trading/ignition_v1/active_positions.json` — 买入仓位记录
- `~/.hermes/trading/ignition_v1/history.jsonl` — 历史交易
- `~/.hermes/trading/ignition_v1/backtest_v2.json` — 回测结果
