# 5分钟分时成交量深度分析法

## 概述

当需要判断个股日内是真突破/假突破/洗盘/出货时，不能只看日线K线。必须拉5分钟K线（`period="5", count=40`），逐阶段拆解量价关系。

## 数据获取

```
mcp_intel_fetch_kline(symbol="688331", period="5", count=40)
```

返回每根5分钟K线的 OHLCV，覆盖约3.5小时（40×5=200分钟）。

## 五阶段分析法

### 阶段一：开盘定位（9:30-10:00）

看开盘15-30分钟的价格方向和成交量。

| 模式 | 特征 | 含义 |
|------|------|------|
| 低开缩量 | 开盘砸-2~3%，量<20万/5分 | 集合竞价洗盘，非出货 |
| 低开放量 | 开盘砸-3%+，量>30万/5分 | 恐慌抛售，谨慎 |
| 高开缩量 | 跳空+2%+，量<15万 | 试盘，看后续能否放量 |

### 阶段二：底��吸筹区（10:00-11:00）

找到全天最大5分钟成交量所在位置。

**关键判定**：
- 最大量出现在**拉升途中**（价格涨+量放大）→ 主力买盘 ✅
- 最大量出现在**下跌途中**（价格跌+量放大）→ 出货 ❌
- 最大量出现在**冲高回落顶部** → 诱多出货 ❌

**量价对比**：
- 拉升阶段每根5分K的量是否递增？递增=资金持续进场
- 回调时量是否萎缩？萎缩=浮筹被锁定

### 阶段三：冲顶放量（11:00-11:30）

上午收盘前是否出现冲顶放量。

| 模式 | 含义 |
|------|------|
| 冲高放量（量>25万）再创新高 | 强势，午后继续看涨 |
| 冲高放量但未创新高 | 双顶风险 |
| 冲高缩量 | 动力不足，午后可能回落 |

### 阶段四：午后缩量区（13:00-14:00）— 最关键的判断窗口

这是全天最重要的阶段。午后一个半小时的成交量变化直接揭示筹码结构。

**量级判断**：
- 5分钟成交量 < 5万 → 极致缩量，浮筹殆尽 ⚠️
- 5分钟成交量 5-15万 → 正常午后缩量
- 5分钟成交量 > 20万 → 午后异常放量，方向选择

**与前几日对比**：
- 如果前几日午后放量砸盘，今日午后缩量 → 抛压衰竭，反转信号
- 如果前几日午后缩量，今日午后放量 → 方向选择

**价格行为**：
- 缩量+价格横盘 → 蓄力，方向由翌日开盘决定
- 缩量+价格阴跌 → 无人接盘，弱势
- 放量+价格拉升 → 午后资金进场，强势

### 阶段五：尾盘抢筹/出货（14:00-15:00）

尾盘一小时的量价行为是最诚实的信号。

| 模式 | 量能特征 | 含义 |
|------|---------|------|
| 尾盘放量拉高 | 5分成交回升至早盘70%+，价格收高 | 抢筹翌日，翌日大概率高开 |
| 尾盘放量跳水 | 5分成交异常放大，价格下跌 | 出货/止损盘涌出 |
| 尾盘缩量横盘 | 量维持5-10万，价格窄幅 | 方向不明，等翌日 |
| 集合竞价放量 | 14:55-15:00量>20万 | 机构调仓/大宗对倒 |

## 实战案例：荣昌生物 688331 2026-06-25

### 数据背景
- 前两日（6/23、6/24）连续冲120回落，疑似出货
- 7/1解禁1.93亿股但不能卖出（分红不达标锁定）
- 今日开盘115→砸111.44→V反收119.49（+1.65%）

### 五阶段分析

**阶段一（开盘砸盘 9:30-10:15）**：
115→111.44，5分成交18.3万。缩量砸盘，不是恐慌出货。

**阶段二（底部吸筹 10:15-11:00）**：
10:30出现全天最大量33.8万股/5分，此时价格从113涨到114.72。**最大量在拉升途中 = 主力买盘**。如果出货，最大量应在高位下跌时出现。

**阶段三（冲顶 11:00-11:30）**：
11:05第二大量35.5万股，价格117→118。放量突破118。上午收119.79。

**阶段四（午后缩量 13:00-14:00）**：
13:55出现全天最低量3.9万股/5分。13:30仅8.1万股。一个半小时内量从30万萎缩到3.9万。**极致缩量 = 浮筹耗尽 = 无人卖出。**

对比前两日：6/23午后放量砸盘，6/24午后缩量但有抛压。今日午后缩到地量。

**阶段五（尾盘抢筹 14:00-15:00）**：
14:50量回到24.5万，14:55量24.3万，15:00量16.8万。尾盘三根线量能回到早盘的70%+，价格从118.8拉到119.49。**尾盘放量拉高 = 抢翌日。**

### 综合判断

今日分时全貌：跌→吸→拉→缩→抢。对比前两日的冲高回落模式，今日本质不同——午后不再有抛压，尾盘有资金抢筹。判定为洗盘结束后的蓄力拉升，翌日高开过120概率>60%。

## 常见误判

1. **把开盘缩量砸盘当出货**：开盘15分钟缩量下跌通常是洗盘，不是机构出货。机构出货需要量和时间。
2. **忽视午后缩量**：午后缩量是全天最重要的信号。如果缩到地量（<5万/5分），说明筹码被锁定，方向即将选择。
3. **把冲高回落当反转失败**：如果回落时缩量（而非放量），往往只是洗盘而非见顶。
4. **不对比前几日分时**：单日分时必须对比前2-3日分时才有意义。同样的K线形态，缩量背景下含义完全不同。
