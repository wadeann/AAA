# 第三方文章/观点分析回测流程

当用户分享第三方文章（微信公众号、雪球、微博等）要求分析其观点时，执行以下标准流程。

## 标准流程

### Step 1：抓取文章全文
- 微信公众号链接 → 使用 `wechat-article-reader` skill 中的 `fetch_article.py`
- 其他来源 → 浏览器或 curl 获取

### Step 2：提取核心观点
提取文章中的具体判断（板块推荐、方向判断、时间窗口等），量化为可回测的指标。

### Step 3：用实际数据交叉验证 ⚠️ 核心步骤

#### 3a. 确定板块龙头（严禁凭名字猜测！）
```
# 用问财查市值排名，获取实际龙头
mcp_intel_wencai_search("XX行业 市值排名前五")
mcp_intel_wencai_search("XX概念 总市值从高到低排序前5")
```
**❌ 绝对禁止**：凭印象或名字选股（如"中国软件"≠软件开发龙头，实际龙头是同花顺/金山办公/科大讯飞）
**✅ 正确做法**：先用 wencai 查市值排名，取实际前3-5名作为跟踪标的

#### 3b. 拉K线数据验证（100根30分钟线）
```
mcp_intel_fetch_kline(symbol, period="30", count=100)
```
必须拉100根（足够覆盖浪型全貌），不能只看20根。

#### 3c. 查资金流向
```
mcp_intel_wencai_search("XX板块 近10日资金净流入")
```

#### 3d. 查板块指数
```
mcp_intel_query_data("板块指数代码")
```

### Step 4：输出分析结论
逐条验证文章观点，标注：
- ✅ 数据支持
- ⚠️ 逻辑合理但数据未确认
- ❌ 数据不支持

### Step 5：建立回测跟踪文件
在 `~/.hermes/backtest/` 下创建 Markdown 文件，包含：
- 文章来源、发布时间、核心观点
- 我们的分析结论
- 跟踪标的列表（含基准价格）
- 每周回测记录表

模板见 `templates/backtest-template.md`

## 常见陷阱

1. **凭名字选龙头** — 2026-08-09 教训：选了"中国软件"和"用友网络"当软件龙头，实际前三是同花顺(1805亿)、金山办公(1233亿)、科大讯飞(1046亿)。用友市值仅400亿排第9，中国软件不在前十。
2. **K线根数太少** — 20根30分钟K线覆盖时间太短，看不清浪型全貌
3. **不查资金流向** — 纯K线分析缺少量价配合
4. **分析完不建回测文件** — 观点不跟踪等于白分析
