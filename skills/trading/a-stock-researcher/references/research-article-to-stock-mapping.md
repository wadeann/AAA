# 上游研究文章 → A股供应链映射流程

> 当用户分享上游供应链/材料/零部件研究文章并说"找出对应A股"时

## 触发语

- "找出对应A股"
- "映射到A股"
- "有什么A股标的"
- "材料/设备/零部件对应什么A股"
- 用户分享了特定材料/技术节点的研究文章（如PCB材料、电子布、硅微粉等）

## ⚠️ 与现有模式的区别

此模式≠"美股映射"（us-a-share-sector-mapping）、≠"产业全景深度分析"（supply-chain-analysis-framework）、≠"第三方文章验证"（third-party-article-analysis）。它是**从上游研发报告/调研纪要中提取技术节点→逐节点映射A股**。用户给了你"答案的搜索引擎"（文章中的材料清单），你的任务是"给每个节点找到对应的A股上市公司"。

## 标准流程

### Step 1：提取文章全文（如果来源是微信公众号）

```bash
python3 ~/.hermes/skills/wechat-article-reader/scripts/fetch_article.py "https://mp.weixin.qq.com/s/XXXXX"
```

不论source，先获取全文，识别文章中的：

- **材料/零部件节点**：文章提到了哪些具体的材料（电子布、硅微粉、树脂等）、零部件（CCL覆铜板、铜箔等）、技术（PTFE方案、HVLP铜箔等）
- **用量/级别信息**：M8/M9/M10级别、Low-Dk一代/二代布、月出货量等
- **供应商名称**：斗山、台光、生益等 — 识别哪些是外资（需找A股对标），哪些是A股

### Step 2：按环节分节点，逐节点查询A股标的

每识别一个材料/技术节点，执行一次问财查询：

```python
# 精确查询，带"主营产品"约束排除纯概念股
mcp_intel_wencai_search("XX材料 概念股 主营产品")
mcp_intel_wencai_search("XX概念 A股上市公司 主营产品")
```

**关键技巧**：
- 用"主营产品"约束比纯"所属概念"更可靠（概念分类可能太宽泛或不准确）
- 对已识别的外资对标（斗山 → 无A股、台光 → 台光未有A股对应但有生益科技对标），用其在A股的竞争对手替代
- 上市公司主营业务需要真实查询确认，不能仅凭概念标签

### Step 3：批量行情查询

```python
mcp_intel_query_batch_data(["600183.SH", "603256.SH", "688300.SH", ...])
```

用真实行情确认：
- ✅ 有效标的：真实交易、有成交量、有流动性
- ❌ 淘汰：ST股、停牌、成交量过低（<500万/日）

### Step 4：财务基本面验证（Top 3关键标的）

对第一梯队的2-3只标的拉利润表确认：

```python
mcp_intel_get_financial_report(symbol, num=2)
```

核心看：营收（确认该业务是其主业而非概念贴牌）、净利润（确认盈利）、毛利率（确认壁垒）

### Step 5：排名与结构化输出

按**稀缺性×壁垒×价格弹性**分三档输出：

| 梯队 | 标准 | 仓位建议 |
|------|------|---------|
| **第一梯队** | 纯正标的/唯一映射/主业为此/壁垒高 | 深入研究，可考虑关注 |
| **第二梯队** | 有大体量业务/但不是纯正单一标的 | Beta跟涨逻辑 |
| **第三梯队** | 概念沾边/远期/想象成分大 | 仅知识整理，不宜追 |

每只标的只需一行核心信息：**代码、名称、现价、涨跌幅、一句话核心逻辑**

### Step 6：↑ 顶部标注大盘环境警示

大盘退潮期，必须标注：**当前大盘退潮/initial_ebb/panic_ebb，以上仅为行业研究与知识整理，个股操作需要等待市场情绪回暖后择时执行。**

## 2026-09-15 实战案例：PCB材料

### 输入
微信公众号《PCB材料更新》（调研纪要·2026-09-15），内容包括：
- Rubin主力方案（M8+二代布+四代铜）
- LPU方案（M9二代布&M9Q）
- Rubin Ultra PTFE方案概率提升
- 硅微粉、树脂升级、电子布涨价等

### 识别出的节点

| 文章节点 | 对应环节 | A股标的 |
|---------|---------|--------|
| CCL覆铜板 | M9/M8覆铜板 | 生益科技600183、华正新材603186、南亚新材688519、金安国纪002636 |
| 电子布/二代布 (Low-Dk紧缺涨价) | 电子级玻璃纤维布 | 宏和科技603256（最纯正）、国际复材301526、中材科技002080、中国巨石600176 |
| 硅微粉 | 球形硅微粉 | 联瑞新材688300（唯一纯正） |
| 树脂(PPO→BCB碳氢) | 电子级树脂 | 呈和科技688625（PPO新贵，批量供货供不应求）、宏昌电子603002（环氧树脂） |
| PTFE方案 | 聚四氟乙烯高频板 | 高斯贝尔002848、协和电子605258 |
| 四代铜(HVLP) | 超低轮廓铜箔 | 宝鼎科技002552 |

### 排名结果

**第一梯队**：宏和科技603256（电子布最稀缺环节）、联瑞新材688300（硅微粉双buff）、呈和科技688625（树脂新贵）

## 关键要点

### 文章类型识别

同一篇文章可以根据用户意图走不同流程：
- 用户说"分析这篇文章" → 走 `third-party-article-analysis.md`（验证观点）
- 用户说"找出对应A股" → 走本流程（节点→标的映射）
- 用户说"深度分析XX产业链" → 走 `supply-chain-analysis-framework.md`（全景分层）

### 数据验证要点

- 处理非标准股票代码：北交所已全量迁移至920前缀
- 跨市场对标（斗山/台光/生益）：用竞争关系而非直接映射
- 涨停标的（如华正新材+10%）需标注，不应追入

### 常见陷阱

1. ❌ 概念太宽泛就出结果（如"PCB概念"有239只）→ 必须加主营产品约束精确到节点
2. ❌ 忽略外资对标 → 斗山是韩国公司，台光在台湾，A股只有竞争对手生益科技/华正新材
3. ❌ 只给标的列表不给排名 → 用户需要"哪个最值得关注"
4. ❌ 忽略大盘环境 → 退潮期的映射结果必须先给出环境警示
5. ❌ 混淆"文章中的公司名"和"A股可比标的" → 文章提"斗山"你不能说"A股有斗山"，要说"A股对应标的是XX"
