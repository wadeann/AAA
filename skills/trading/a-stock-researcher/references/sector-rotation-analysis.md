# 板块轮动分析（Sector Rotation Analysis）

当用户问"科技股暴跌后下一个热门板块是哪个"或类似的板块轮动问题时，使用以下方法。

## 核心数据源（3轮并行调用）

### Round 1 — 板块涨跌排名（wencai_search）

```
mcp_intel_wencai_search("近一个月涨幅最大的行业板块 涨幅排名前10")
mcp_intel_wencai_search("近一个月跌幅最大的行业板块 跌幅排名前10")
```

## 核心数据源（3轮并行调用）

### Round 1 — 板块涨跌排名（wencai_search）

```\nmcp_intel_wencai_search("近一个月涨幅最大的行业板块 涨幅排名前10")\nmcp_intel_wencai_search("近一个月跌幅最大的行业板块 跌幅排名前10")\n```\n\n返回同花顺三级行业指数，含涨跌幅数据。时间窗口用"近一个月"或指定日期范围如"20260506-20260605"。

### Round 2 — 板块资金流向（🔴 核心数据源，必须调用）

**每日资金流向（最高优先级查询，320个板块全覆盖）：**
```\nmcp_intel_wencai_search("今日板块资金净流入排名 行业板块 {今天日期}")\n```\n\n此查询返回全部320个同花顺二级/三级行业指数的资金净流入额（排序降序），是板块轮动分析的**最核心数据源**。数据字段包括：指数代码、指数简称、资金净流入额（当日）、指数类型（二级/三级）、成分领域。

**解读规则（经实战验证 2026-06-13）：**
- 净流入 > 30亿 = 大级别资金介入（如证券+71.5亿、电池+46.3亿）
- 净流入 10~30亿 = 中等级别资金关注（如钨+23亿、稀土+16.8亿）
- 净流入 < 10亿 = 散户/小资金，信号弱
- 净流出绝对值 > 50亿 = 大级别资金撤退（如半导体-87.5亿）

**子板块分化识别（关键技巧）：**
注意同一二级行业下三级行业的分化。如 2026-06-13 锂电池+31.4亿但"锂"-1.78亿，说明电池整机受追捧但锂原料被抛弃。亿纬锂能受益（电池整机），但天齐锂业承压（锂原料）。

### Round 3 — 全球信号 + 宏观（mcp 工具）

```\nmcp_intel_fetch_market_health() → A股大盘健康度（含资金流出总额）\nmcp_intel_fetch_hot_signals() → 全球热点事件（补充用，信号有限）\n```\
mcp_intel_fetch_hot_signals() → 全球热点事件（含情绪评分）
mcp_intel_fetch_market_health() → A股大盘健康度（含资金流出总额）
```

## 交叉验证框架

板块轮动分析必须有**三个维度交叉验证**：

| 维度 | 工具 | 验证什么 |
|------|------|---------|
| 涨幅 | wencai 板块涨幅排名 | 谁在涨 |
| 资金 | wencai 资金净流入 | 谁在被买 |
| 事件 | fetch_hot_signals | 为什么涨 |

**只做涨幅排名不做资金验证 = 假信号。** 涨幅大但资金在流出的板块是诱多。

## 分析输出结构

```
1. 全球背景（科技/大宗商品/汇率变化对A股的影响）
2. 板块涨幅 Top10（表格）
3. 板块跌幅 Top10（对比，识别被抛弃的板块）
4. 本周资金流向 Top10（验证涨幅是否可持续）
5. 交叉验证结论：
   - 🥇 最确定方向（涨幅+资金+事件三者共振）
   - 🥈 次确定方向（其中两项共振）
   - ⚠️ 高风险方向（只有涨幅、资金在流出 = 诱多）
6. 持仓风险对照：检查用户持仓是否在下跌板块中
7. 操作建议（具体到关注标的方向，不下单）
```

## 实战验证的浪型信号模式（2026-06-13 BULL_3_LATE 案例）

### 判定信号组合：科技出逃 + 金融承接 + 资源接力

当日资金数据：
- 半导体-87.5亿、通信设备-57.5亿、消费电子-28.4亿 → 科技三剑客集体大撤退
- 证券+71.5亿、银行+60.4亿、保险+15.7亿 → 金融板块集体承接（合计~148亿）
- 小金属+38.5亿、钨+23亿、稀土+16.8亿 → 资源股在接棒（合计~78亿）
- 光伏全链条流出-8~64亿不等 → 旧主线清仓

**判定结论：`market_phase = BULL_3_LATE`（长3浪末期）**
- 长3浪主角（科技三剑客）在集体撤离
- 金融板块（证券+银行+保险）聪明钱提前布局大33浪
- 资源接力（小金属+钨+稀土）

### 与持仓的交叉验证方法

1. 先拉 wencai 320板块资金流向
2. 对每只持仓标调用 wencai_search 确认所属行业/三级行业

4. 标记 🟢（净流入>10亿）/ 🟡（净流入0~10亿或净流出<5亿）/ 🔴（净流出>5亿）

## 全球传导链路

当分析A股板块轮动时，必须关注：
1. 上周五美股涨跌（特别是科技七巨头）
2. 今日亚太开盘（韩国KOSPI、日经225、恒指）
3. 大宗商品（原油、铜、铁矿石）

全球风险偏好下降时，A股科技股首当其冲，红利/公用事业最抗跌。

## 关键信号：工具适用性（实战校准 2026-06-13）

### fetch_hot_signals — 补充用，非主力

`fetch_hot_signals` 在板块轮动分析中**不是主力工具**。实测发现：
- 返回结果大量重复（同一条新闻出现5-7次）
- 多为外交/地缘类低信号新闻，对A股板块轮动指导有限
- score 普遍为 0.0~0.4，极少出现高 impact 信号
- **适用场景**：全球性黑天鹅事件（韩国熔断、日经暴跌、地缘冲突升级）

### 板块资金流向 wencai 查询 — 真正的主力

`wencai_search("今日板块资金净流入排名 行业板块 {日期}")` 返回 320 个板块的精确资金流数据，是板块轮动判断的**决策级数据源**。优先级远高于 hot_signals。

### fetch_market_health — 宏观环境锚定

提供 health_score（92.9=极强）和大盘指数，用于判断是 BULL/NEUTRAL/BEAR 环境，是轮动分析的前提条件。

## Pitfalls

1. **只看涨幅不看资金** → 涨幅大但资金流出的板块是短线诱多，追进去就是站岗
2. **忽略全球背景** → 美国科技股暴跌的第二天，A股大概率低开，板块轮动逻辑要先看大盘环境
3. **把概念炒作当轮动** → 钙钛矿、电子纸这种小众概念虽然资金流入高，但盘子太小做不了主力配置
4. **不检查用户持仓风险** → 分析板块轮动必须同步检查用户持仓是否在被抛弃的板块中
5. **依赖 fetch_hot_signals 做轮动决策** → hot_signals 返回外交类低信号新闻为主，对A股板块轮动指导有限，必须以 wencai 资金流向为决策级数据源
6. **不识别子板块分化** → 同一二级行业下三级行业可能资金流向相反（如锂电池+31亿但锂原料-1.8亿），需细化到三级行业
