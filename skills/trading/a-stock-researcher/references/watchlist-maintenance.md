# 自选股维护规则（MCP Tools: get_watchlist / update_watchlist）

## MCP 工具

| 工具 | 参数 | 说明 |
|------|------|------|
| `mcp_intel_get_watchlist` | 无 | 返回自选股列表 JSON |
| `mcp_intel_update_watchlist` | action: add/remove, symbol, name, reason | 增删自选股 |

数据存储：`~/.hermes/trading/watchlist.json`
格式：`{"watchlist": [{"symbol": "CODE.SH", "name": "名称", "added_date": "YYYY-MM-DD", "reason": "加入理由", "status": "active"}], "last_updated": "ISO8601"}`

## 双层维护机制

### 日内增量维护（盘前扫描 / 研究员 Step 7 执行）

在盘前扫描和盘中评估流程中，研究员有机会做增量维护：

**何时添加：**
- 研究员 Step 4 形态扫描或 Step 5 消息驱动发现的强候选（confidence ≥ 0.75）
- 盘中扫描发现强势板块启动，龙头股不在自选中
- 用户提供"关注XXX"指令

**何时删除：**
- 自选股中出现基本面严重恶化（PE > 200、业绩暴雷、ST风险）
- 标的已清仓且不再具有短期催化剂

**操作方式：** 在研究员 Step 7 自选股检查环节，发现上述情况时调用 `mcp_intel_update_watchlist`

### 周度深度清理（周五 20:00 专项 a-stock-watchlist-update 执行）

详见 `a-stock-watchlist-update` skill。完整审查所有自选股：

**移除标准（满足任一即移除）：**
1. 基本面恶化（连续2季度营收/利润下滑、PE畸高）
2. 连续2周无任何形态信号触发（不活跃）
3. 所属板块趋势转弱（板块指数跌破20日均线）
4. 流动性萎缩（日均成交额 < 5000万）

**新增标准（全部满足才新增）：**
1. 所属板块为当周强势板块
2. 基本面健康（PE合理、业绩正增长）
3. 形态高胜率信号触发（technical_breakout 优先于 news_event）
4. confidence ≥ 0.75

## 注意事项

- watchlist.json 在首次调用 update_watchlist 时自动创建，无需手动建文件
- symbol 格式必须带后缀：上海.SH / 深圳.SZ（如 600519.SH, 000001.SZ）
- reason 字段必须写明具体理由，不能留空
- 添加和删除同一 symbol 不会叠加，只保留最新 status

## 批量淘汰审查标准（2026-08-22 新增）

当用户要求"审查自选股淘汰"或自选股超过30只需要清理时，执行以下系统性审查：

### 审查流程

1. **全量拉数据**：`query_batch_data` 一次拉全部自选股实时行情 + `wencai_search` 批量查近5日涨跌幅和资金流向
2. **逐板块分组**：按行业/概念将自选股分组，便于发现板块性衰退
3. **四维评分淘汰**：

### 淘汰硬标准（满足任一即淘汰）

| 维度 | 阈值 | 说明 |
|------|------|------|
| **量价双杀** | 近5日跌幅>5% **且** 主力资金净流出 | 趋势+资金双弱，短期无反转信号 |
| **流动性枯竭** | 近5日日均成交额 < 5000万 | 无法正常进出，北交所小票尤甚 |
| **标签错配** | 代码与自选股中标注的名称/逻辑不匹配 | 如688825被标注为"盛美上海"实际是"长鑫科技" |
| **概念退潮** | 所属板块不在当前资金TOP10且近5日板块跌幅>3% | 板块性衰退，个股难以独善其身 |

### 观察降级标准（不淘汰但标记警惕）

| 维度 | 阈值 | 说明 |
|------|------|------|
| **资金背离** | 跌幅>5%但资金仍在流入 | 可能是有资金在吸筹，需要再观察 |
| **龙头回调** | 板块龙头跌幅>10%但基本面未变 | 可能是上涨中的正常回调 |
| **刚加入** | 加入不到2周 | 给新标的更多观察时间 |

### 输出格式

淘汰结论分三组：❌建议淘汰 / ⚠️观察降级 / ✅保留，每组列出代码+名称+5日涨跌+资金流向+淘汰理由。用户确认后执行 remove 操作。
