# 交易结果主动同步格式

## 触发条件

每次执行买入/卖出委托（包括分批成交）后，必须在飞书主动推送交易结果给用户。

## 格式

```
{股票中文名}({代码}) {方向} {数量}股@{单价} 总金额{总金额} 今日盈亏+/-{X}元

{说明：成交状态/申报编号/分批结数}
```

## 示例

```
云南锗业(002428) 买入 200股@18.50 总金额3700元
　全部成交

紫金矿业(601899) 卖出 500股@35.15 总金额17575元 今日盈亏+1,200元
　全部成交，盈亏含累计浮盈
```

## 批量同步

多笔交易用空行分隔，按时间倒序（最新的在最前）。

## 无交易时的要求

盘中不强制报平安。但有交易时必须第一时间推送，不等用户追问。
