## 教训

### 1. 建议归属问题（严重）
agent 提出荣��� 108 卖出建议 → 用户拒绝 → agent 随后说"你之前说在 108 卖出" → 用户愤怒："荣昌是我自己说要卖的吗？"
**教训**: agent 提出的建议，agent 负责。绝不能把 agent 的建议归咎到用户身上。用户撤回建议时直接执行，不辩解。

### 2. 执行闭环缺失（严重）
南大 63.3 的买点 09:30 就出现了，但 agent 只设置了监控 cron 而没有调用 `place_order`。
**教训**: 用户明确给出买入价格和标的时，agent 必须完成下单闭环。设监控不执行 = 失职。

### 3. Exec 持仓同步（已知但未妥善处理）
周末风控拒绝交易导致 exec 系统无法同步持仓，所有卖出报 "Insufficient shares"。
**教训**: 当卖出全部失败且原因为 available=0 时，应**直接告知用户去券商端手动卖出**，而不是反复尝试或让用户困惑。这是一个已知的环境限制，不是操作错误。

### 4. 南大光电追高问题
原计划 63.3 买入，最终用户 65.47 买入（+3.4%）。
**教训**: 当标的开盘已高于计划价 >3%，应明确建议等待回踩，不追高。如果用户坚持追高，agent 应记录这个决策偏差。

### 5. 长盈通停牌核查
6/17 起停牌核查（5月-6月累计涨 249%，PE 1130 倍）。
**教训**: 涨幅过大+基本面不支撑的标的，即使技术面完美也要警惕监管风险。1130 倍 PE 是明显的非理性炒作信号。
