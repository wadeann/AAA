# 分市场熔断：防止窄基指数误伤全市场

## 适用场景
市场状态机、盘中动态熔断器或交易闸门使用多个指数判断系统性风险时，必须区分宽基风险与窄基/风格风险。单一窄基指数走弱，不等于全市场恐慌。

## 典型误判
旧逻辑把“四大指数任意一个跌幅 <= -2%”直接写成 `regime=极寒`、`sell_only_mode=true`。现场曾出现科创50约-2.08%，但上证约+0.26%、深证约-0.05%、创业板约-0.15%，跌停仅4家、炸板率约23.6%。这是科创风格局部下跌，不应冻结其他市场。

## 正确分级规则

### 全局熔断
任一条件成立可进入全局只卖不买：
- 跌停家数 >=20；
- 炸板率 >=45%；
- 上证、深证或创业板等宽基指数任一 <=-2%；
- 科创50 <=-2%，同时宽基或市场情绪同步恶化；
- 核心数据失真且无法证明新鲜度，按 Fail-Closed 处理。

### 分市场隔离
若仅科创50 <=-2%，上证/深证/创业板均 >-1%，跌停<20且炸板率<45%，输出：

```json
{"tripped":false,"scope":"STAR_ONLY","blocked_market_types":["STAR"],"isolated_star_crash":true}
```

行为：科创板买入候选拒绝；其他市场候选继续经过原有个股、板块、资金和风险门禁；不得写入全局 `sell_only_mode=true`。

## 状态自愈
若旧版逻辑已因“科创50单指数跌超2%”写入全局熔断：
1. 读取市场状态与策略参数；
2. 仅当旧原因明确指向科创50，且实时条件满足孤立科创下跌时解除；
3. 写入 `sell_only_mode=false` 与 `blocked_market_types=["STAR"]`；
4. 保留其他题材隔离、黑名单和红线状态，不得顺手清空。

## 候选闸门

```python
tripped, info = intraday_dynamic_check(...)
if tripped:
    reject_global()
elif get_stock_market_type(symbol) in info.get("blocked_market_types", []):
    reject_market_scope()
else:
    continue_normal_gates()
```

分市场隔离只能阻断对应市场，不可让遗留全局状态再次误杀其他市场。

## 最小回归测试
1. 孤立科创下跌 → `STAR_ONLY`，不全局熔断；
2. 688候选被隔离，600/000/002/300/920候选不因此被动态熔断；
3. 科创与宽基同步下跌，或跌停/炸板达到阈值 → 全局熔断；
4. 旧科创全局熔断可自愈为分市场隔离；
5. 自愈不清空其他题材隔离和独立红线。

验收需同时提供：测试输出、生产状态文件回读、科创板与非科创板候选的门禁差异证据。
