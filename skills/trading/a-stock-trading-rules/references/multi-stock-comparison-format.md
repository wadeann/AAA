# 多股对比分析格式规范

## 触发场景

用户要求同时分析两只或以上标的时（"分析下XX和YY"、"对比XX和YY"），使用此格式。

## 输出结构

### 单只标的分析（对每只标的）

```
## 股票名 代码 — 现价 +/-涨跌幅

K线结构（周期）：
[关键转折点的日期→价格→量能 →涨跌序列 → 当前定位]

结构定性：
[一句话判断：主升浪/下跌反弹/A浪下跌/震荡等]

[关键证据：量价配合/主力建仓/出货痕迹]
```

### 对比总结（放在最后）

```
## 对比结论

| | 标的A | 标的B |
|---|---|---|
| 结构 | 定性 | 定性 |
| 量价 | 证据 | 证据 |
| 催化剂 | 来源 | 来源 |
| 操作 | ✅/⚠️/❌ + 理由 | ✅/⚠️/❌ + 理由 |
```

### 决策输出

最后一行给明确结论：`[标的X]比[标的Y]靠谱得多。要不要买[标的X]？`

## 核心规则

1. **100根K线还原全貌**：30分钟线拉100根（覆盖约5个交易日），不要只拉20根。浪潮信息从85跌到69如果只看最近20根K线，会误判为"底部反弹"而错过7/17-7/22的顶部出货结构。
2. **先定性再定量**：先判断处于什么阶段（主升浪/下跌趋势/震荡/反弹）再谈价格。定性错了，所有目标价都是噪音。
3. **量价不分离**：每一段价格描述必须带对应的量能（放量/缩量/巨量），量是价的确认信号。
4. **❌要敢于说"不碰"**：下跌趋势/反弹陷阱直接标❌，不模棱两可。"等回踩"、"看情况"、"关注一下"都是不清晰输出。
5. **对比表必须出现**：多股分析结束时必须有对比表，用✅/⚠️/❌直接表态。
6. **最后留钩子**：以"要不要买"结尾，不替用户决定但给出明确偏好。

## 反面案例（本次浪潮信息）

如果只看最近20根30分钟K线（7/31-8/4），看到的是：69→75→73→74，底部反弹形态，会误判为"可以买"。

拉100根后看到全貌：7/17 85暴跌→7/22 95.5巨量顶部→持续阴跌至69，这是A浪下跌后的B浪反弹陷阱。顶部76亿/30分钟的巨量+冲高回落长上影=典型出货。

**教训**：分析新股时必须拉足历史K线覆盖完整浪型周期，不能只拉最近一段。
