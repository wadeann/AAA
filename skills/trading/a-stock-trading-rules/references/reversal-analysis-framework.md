# 反转分析框架 — 四维否决矩阵实战核查手册

> 上层 skill: `a-stock-trading-rules`
> 文件: `scripts/l2_interface.py` (get_trend_acceleration_l1 可辅助趋势判断)
>
> 创建: 2026-09-07
> 背景: 用户问"昊华科技反转了吗" → 验证了反转判定框架的有效性
> 案例: 昊华科技(600378) — 一票否决(MA死叉+MACD水下死叉), 四维2/17 → ❌不是反转

## 一票否决的完整执行路径

当用户问"X股票反转了吗"，的完整执行链：

```
1. query_data(symbol) → 当前价/涨幅/量
2. get_technical_indicators(symbol) → MA5/10/20, MACD, KDJ, RSI, BOLL
3. get_fund_flow(symbol) → 当日/5日/20日主力净流
4. fetch_kline(symbol, period="D", count=60) → 完整K线结构
5. search_news(symbol) / wencai_search → 板块新闻/催化
6. 执行一票否决检查 → 被否直接❌输出，不继续
7. 四维矩阵评分 → 按分数给出结论
```

## 一票否决条件的具体数据字段对照

### 条件1: MA空头排列

```
从 get_technical_indicators 提取:
  ma.MA_5  = closePrice 的 5日移动均线
  ma.MA_10 = 10日移动均线
  ma.MA_20 = 20日移动均线

判定:
  MA_5 < MA_10 < MA_20 → 标准空头排列 → ❌否决
  MA_5 > MA_10 但 MA_10 < MA_20 → 短多长空 → ⚠️加重审查
```

**坑**: `fetch_kline` 返回的每根K线也带 `ma5`, `ma10`, `ma20` 字段,但 `get_technical_indicators` 的 `ma.MA_*` 是最新的。优先用 `get_technical_indicators` 的字段。

### 条件2: MACD死叉

```
从 get_technical_indicators 提取:
  macd.DIF   = DIF快线
  macd.DEA   = DEA慢线
  macd.MACD  = MACD柱 (DIF - DEA) × 2 (注意: 有的源返回柱值,有的返回2倍)

判定:
  DIF < DEA → 死叉 → 否决
  DIF < 0 AND DEA < 0 → 水下死叉 → 双重否决

注意:
  MACD柱翻红(DIF即将上穿DEA) ≠ 金叉已确认
  金叉 = DIF > DEA 连续维持2根日K线
  单日柱翻红不能推翻死叉状态
```

**典型误判**: 用户看到MACD柱翻红(红色柱)就认为反转。幸存者偏差——每天都有几百只股票MACD柱翻红,其中大部分只是反弹。需结合MA排列+资金面确认。

### 条件3: K线结构 — 下降趋势线段识别

```
从 fetch_kline(period="D", count=60) 提取最近60根日线:

识别最近的A-B-C下跌结构:
  A浪: 从最高点放量下跌到第一个低点L1
  B浪: 从L1缩量反弹到H2 (通常反弹A浪跌幅的30-50%)
  C浪: 从H2再次放量下跌到L3 (可能低于L1也可能不破)

反转必需条件:
  - C浪必须出现放量底分型 (见下面"底分型定义")
  - 后续反弹必须放量突破B浪高点H2 + MA20
  - 突破后回踩不破H2和MA20

如果是单纯的下行缺口→横盘→再下行结构,无底分型 → ❌否决
```

**底分型定义**:
```
底分型 = 第N根K线最低点是周围至少3根K线中的最低
  即 low[N-1] >= low[N] <= low[N+1]
  close[N] > open[N] (阳线确认)
  成交量 > 前日 x 1.5 (放量确认)

如果只有最低点但未放量+收阴=假底分型(盘中试盘)
```

## 四维矩阵实战数据提取

### 维度1: MA排列 (满分4分)

数据源: `get_technical_indicators(symbol) → ma.*`

| 检查项 | 判定条件 | 分数 | 提取代码 |
|:------|:--------|:---:|:--------|
| 金叉 | ma.MA_5 > ma.MA_10 | +2 | 同时检查 prev_close 是否在MA5上方 |
| 方向向上 | ma.MA_10 比5日前高 | +1 | 需要历史数据,无法单次判断 |
| 上穿MA20 | close > ma.MA_20 | +1 | 现在价比较 |
| 均线粘合 | MA5-MA10-MA20间距<3%且开始发散 | +0.5 | |(备用)

**实战注意**: `get_technical_indicators` 返回的是当日收盘后的均线值。
盘中11:00查询时, 均线值基于昨日收盘计算, 不等于盘中真实MA位置。
需要结合 `query_data` 的 `price` 判断是否已经突破/跌破。

### 维度2: 主力资金 (满分4分)

数据源: `get_fund_flow(symbol) → data.*`

| 检查项 | 判定条件 | 分数 |
|:------|:--------|:---:|
| 当日主力净流入 > 0 | MainNetFlow > 0 | +1 |
| 5日净流拐头 | MainNetFlow5D > 上一交易日的MainNetFlow5D(需记录) | +1 |
| 超大单承接 | JumboNetFlow > 0 且 > BlockNetFlow绝对值 | +1 |
| 融资余额企稳 | FinanceValueDOD > -1% (日环比止跌) | +1 |

**关键字段别名**: 不同源可能字段名不同:
- `MainNetFlow` = 当日主力净额（含超大单和大单）
- `JumboNetFlow` = 超大单净额（>=500万单笔）
- `BlockNetFlow` = 大单净额（>=100万且<500万）
- `MidNetFlow` = 中单净额
- `SmallNetFlow` = 小单净额（散户）

**典型形态**: 反转期资金特征
- 前期: MainNetFlow持续负值(20日-10亿+), 股价阴跌
- 中期: MainNetFlow由负转正(JumboNetFlow率先止跌), 股价企稳
- 确认: MainNetFlow连续3日为正 + JumboNetFlow > BlockNetFlow → 机构在接货

### 维度3: K线结构 (满分5分)

数据源: `fetch_kline(period="D", count=60) → klines[]` + `get_technical_indicators → boll.*`

| 检查项 | 判定条件 | 分数 |
|:------|:--------|:---:|
| 底分型 | 最近3根K线形成底分型且成交量放大 | +2 |
| 回踩不破前低 | 最低点 >= 前一个低点 (L2 > L1) | +1 |
| 突破MA20 | close > boll.BOLL_MID (布林带中轨=MA20) | +1 |
| 布林开口 | 布林带先收缩后开口放大(boll.UPPER - boll.LOWER < 5%时收缩, 现在开口) | +1 |
| 量价配合 | 上涨日成交 > 下跌日成交 x 1.5 | +0.5 |

**K线结构图(hypothetical)**:
```
价格
 ↑
H1≈87 ────┬─────────── A浪起点 (6月顶部)
          │
          │       H2≈55 ─── B浪高点 (可忽略反弹)
          │        ↑
          │        │         C浪下跌到L3≈38 → L4≈45 (当前)
          │        │          ↑
          │   L1≈38┴──────────  底分型?
          │
          └──────────────────────→ 时间
       MA5 < MA10 → 死叉未修复
```

**注意**: 60根日线约覆盖3个月,如果下降趋势超过3个月需减少count(如6个=30根)或增加count到120根覆盖6个月。

### 维度4: 板块共振 (满分4分)

数据源: `wencai_search` + `fetch_sector_history`

| 检查项 | 判定条件 | 分数 |
|:------|:--------|:---:|
| 板块当日TOP20 | 所属板块涨幅排名前20 | +1 |
| 板块5日净流入 | wencai查询板块资金流向 | +1 |
| 同板块涨停>=1 | wencai查询板块内涨停数量 | +1 |
| 板块指数站稳MA10 | 板块指数 > 该板块MA10 | +1 |

**坑**: `fetch_sector_history(code)` 经常返回 error (见 `a-stock-trading-rules` MCP工具清单)。
替代方案—直接 `wencai_search("板块名 今日行情 涨跌幅 资金净流入 板块指数")` 自己构造。

**查询模板**:
```
查询板块涨幅排名:
  wencai_search("A股 概念板块 今日涨幅排名前30 板块名称 涨跌幅 资金净流入")
  → 拿结果跟个股所属板块对照

查询具体板块状态:
  wencai_search("氟化工 今日 板块行情 涨跌幅 资金净流入 成分股涨停数量")
```

## 昊华科技案例复盘(2026-09-07)

### 输入数据
- 现价: 47.57 (+3.98%)
- MA5/10/20: 48.25 / 48.34 / 47.89 (MA5<MA10, 死叉)
- MACD: DIF=-0.04, DEA=-0.24, 柱=+0.39 (即将金叉,但水下)
- KDJ: K=47, D=53, J=34 (偏弱)
- RSI6: 47.6 (中性偏弱)
- BIAS6: -3.0% (短线超卖修复)
- 当日主力净流: +8,567万 (超大单+1.03亿, 大单-1,734万)
- 5日净流: -7.88亿
- 20日净流: -13.2亿
- 融资日环比: -4.07%
- 量: 29.8亿 (放量反弹)

### 一票否决执行
1. **MA死叉**: MA5=48.25 < MA10=48.34 → ❌ 否决
2. **MACD水下**: DIF=-0.04 < 0, DEA=-0.24 < 0 → ❌ 否决 (双重否决)

→ 直接判定❌不是反转,无需执行四维矩阵

### 但如果强行四维矩阵
MA_1/4 (只满足上穿MA20: close47.57 > MA20=47.89 ❌不满足(还差0.32)
资金_0/4 (当日净流入正但5日20日均大幅负)
K线_1/5 (仅\"回踩不破前低\"=45.4 > 8月低点37.5)
板块_0/4 (无同板块共振)

总分: 1/17 → ❌ 反弹,非反转

### 操作结论
```markdown
结论：❌ 不是反转，下降通道超跌反弹修复
确认条件：MA5金叉MA10 + 回踩不破45.79今日低点 + MACD金叉上0轴
阻力：MA10=48.34 → BOLL上轨53.25(密集套牢)
若跌破45.4(前低) → C浪延续,下看BOLL下轨42.53
当前不入场
```
