# 盘前数据时效性陷阱与对策（2026-09-11）

## 问题：盘前行情数据全是昨日收盘

所有 MCP 行情接口（`mcp_intel_query_data`, `mcp_intel_tdx_quotes`, `mcp_intel_query_batch_data`）在 **09:30 开盘前**返回的都是上一交易日的收盘数据。时戳字段隐藏在原始 JSON 中（如 `HQInfo.HQDate=20260910`, `time=2026-09-11T00:31:14`）。

## 检查方法

```python
# 从 mcp_intel_query_data / tdx_quotes 返回结果中提取时间戳
# tdx_quotes 路径: result.HQInfo.HQDate + HQTime (如 20260910, 153302)
# query_data 路径: result.tables[0].rows[0][-1] (如 2026-09-11T00:31:14)

# 若 HQDate != today 或 time 的日期部分 != today → 非当日数据
```

## 数据可用性速查表

| 时间(CST) | 数据状态 | agent 措辞 |
|-----------|---------|-----------|
| 09:15-09:24 | 昨日收盘数据 | "上一交易日收盘" |
| 09:25:01 | 竞价数据（需1分钟内拉取） | "竞价数据已出" |
| 09:25:05-09:30 | 竞价定型盘口 | "竞价开盘价/竞价爆量" |
| 09:31+ | 实时行情数据 | "现价/当前价" |

## 当用户要求分析时（盘前场景）

用户说"今日操作"或"看看这个票"时，agent 必须：
1. 检查 `mcp_intel_is_trading_day` — 确认今日是否交易日
2. 若未开盘 → 数据全是昨日收盘，措辞必须加"昨日"前缀
3. 若用户追问今天开盘价 → 只能等 09:25 竞价数据
