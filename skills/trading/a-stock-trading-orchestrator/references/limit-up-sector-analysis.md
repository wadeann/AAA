# 涨停板板块分析方法论

## 触发条件

用户要求"拉取涨停股票"、"涨停分析"、"昨日涨停板块"、"涨停持续性分析"等。

## 数据获取

### 1. 获取涨停列表

```
mcp_intel_wencai_search(query="昨日涨停股票")
```

返回 `datas` 数组，含 `股票代码`、`股票简称`。通常 50-100 只。

注意：wencai 返回"最近交易日"涨停股。盘中触发时对应上一交易日数据。

### 2. 批量拉取行情

```
mcp_intel_query_batch_data(symbols=[最多30只codes])
```

**硬约束：每批最多 30 只**，超过会丢失数据。75只需分3批。

关键返回字段：
- `change_pct` — 涨跌幅（主板10%，创业板/科创板20%，ST股5%）
- `amount` — 成交额（判断资金参与程度）
- `amplitude` — 振幅（0=一字板，>15%=分歧板，越大分歧越严重）
- `volume` — 成交量

## 分析方法论

### Step 1: 板块归类

无直接板块API，需根据股票名称和行业概念人工归类。常见分类：

| 板块 | 识别关键词 |
|------|-----------|
| 化工/新材料 | 化工、新材、涂料、合成、钛、氟 |
| 半导体/芯片 | 芯片、电子、半导体、封测、集成 |
| 算力/AI/数据 | 信息、数科、通信、数据、智能 |
| 稀土/有色/资源 | 稀土、有色、钼、铜、钴、矿业、粉材 |
| 房地产/建筑 | 城建、地产、装饰、建筑、建工 |
| 新能源/光伏 | 光伏、锂电、电池、太阳能 |
| 医药/生物 | 生物、药业、医疗、制药 |
| 消费/食品/农业 | 食品、啤酒、饮料、农业、能源 |

### Step 2: 主线识别

满足≥2项判定为主线：
1. 板块涨停数 ≥ 4只
2. 板块内有大成交额标的（>10亿）
3. 有龙头封板（一字板或早盘封死）
4. 叠加外部催化（新闻/政策/地缘事件）

### Step 3: 持续性评估框架

| 信号 | 持续性 |
|------|--------|
| 基本面支撑 + 板块效应 + 外部催化 | ★★★★☆ |
| 板块效应 + 大成交额 | ★★★☆☆ |
| 纯游资 + 小成交额 | ★★☆☆☆ |
| ST股涨停 | ★☆☆☆☆ |
| 20cm首板高振幅 | ★★☆☆☆（次日分化概率大）|

### Step 4: 与持仓交叉

- 同板块未涨停品种 → 补涨机会
- 板块走弱品种 → 风险信号
- 直接受益品种 → 重点关注

## 输出格式

1. 板块分布表（板块/数量/代表个股/成交额亮点）
2. 核心主线判断（2-3条主线 + 持续性星级）
3. 20cm标的特别关注
4. 与持仓交叉分析
5. 明日策略建议（值得追/需警惕）

## 常见问题

1. **wencai数量多**：不要跳过，分批拉取全部
2. **ST股（5%涨停）**：单独归类，不混入主线
3. **一字板 vs 换手板**：一字板（amplitude=0）强但次日兑现概率高；换手板（amplitude>10%）更健康
4. **成交额判断**：龙头>10亿，跟风<5亿，纯情绪<1亿
5. **地缘催化**（如美伊冲突）：推升资源/军工/能源，持续性取决于事件演化
