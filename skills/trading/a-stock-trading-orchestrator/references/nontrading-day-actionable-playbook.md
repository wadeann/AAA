# 非交易日基于最近收盘快照输出可执行打法

## 触发场景

用户在非交易日、未开盘时要求“今日打法”，并指定或暗示使用最近交易日收盘数据。

## 核心原则

1. **先执行标准打法入口**：仍须运行 `print_playbook.py`，不得绕开打法生成管道手写“无信号”。
2. **显式锁定数据日期**：使用最近交易日归档计划，例如：
   ```bash
   python3 ~/.hermes/scripts/print_playbook.py --force --no-push --data-date YYYY-MM-DD
   ```
   标题必须写明 `数据基准：YYYY-MM-DD 收盘快照`，不能把归档行情说成今日实时行情。
3. **历史快照隔离**：历史计划优先读取 `trading/plans/plan_YYYY-MM-DD.json`；不得用当天 `market_regime.json`、脏状态或盘中零值重新编译并污染历史判断。
4. **打法必须具名、具价**：即使当前处于退潮或熔断，仍需输出 1–2 个低位候选的：股票名、代码、条件买入区间、止损、目标、仓位和弃买条件。不能只给“观察”“只卖不买”而完全不提供备战标的。
5. **风险与备战分离**：熔断状态不代表删除预案。正确表达是“解除熔断后条件买入”，并明确：指数止跌、全盘解除熔断、所属板块至少两家涨停等触发条件；未满足则全部弃买。
6. **固定三条结构**：
   - 第1条：低位进攻条件预案，最多2只，均具名具价；
   - 第2条：真实持仓防守；
   - 第3条：高位只卖不买具名名单。
7. **高位名单不得挤占低位名额**：≥3板标的用于第3条防守锚；前两只推荐名额优先给首板/1进2低位种子。
8. **候选排序**：优先按板块强度、梯队完整性、成交额、主力资金和技术结构排序；不得依赖 `position_ids` 的偶然文件顺序。
9. **价格真实性**：优先用指定数据日归档收盘价并用K线/资金/筹码/技术数据交叉核验；非交易日不得把缓存接口时间戳伪装成实时价格。
10. **指数和全A中位数禁止零值兜底**：`gem_change_pct`、`median_change` 缺失时必须显示“数据缺失”，绝不能用 `0.00%` 冒充有效行情。历史打法应在 `plan_YYYY-MM-DD.json` 中固化 `market_snapshot`（至少含 `source_date/regime/gem_change_pct/median_change/up_count/down_count/source`），生成时优先读取该快照。全A中位数的问财查询使用明确语义“YYYY年M月D日全A涨跌幅中位数”或“今日全A涨跌幅中位数”，不要使用容易返回空值的模糊“个股中位数”。
11. **候选与可执行买点必须分开说**：有具名候选不等于当前可以买。报告必须明确给出二选一裁决：
    - `当前可执行`：价格、市场、板块和量价条件均已成立，可直接按区间操作；
    - `仅条件预案`：当前没有合适买点，列出下一交易日必须同时满足的触发条件，未满足一律弃买。
    禁止一边给价格区间，一边让用户无法判断究竟能不能买。
12. **用户追问“会是什么形态”时必须给示意**：用简短ASCII图或分步描述展示“竞价/开盘回踩 → 缩量承接不破支撑 → 放量重新突破触发价”的合格形态，同时画出“高开冲顶后持续回落”的弃买反例。示意图只解释触发结构，不能代替具名股票、价格区间、止损和弃买条件。

## 可执行性裁决话术

```text
当前裁决：没有可立即执行的买点；有2只下一交易日条件候选。
只有当【指数止跌并解除熔断 + 所属板块至少2家涨停 + 个股回踩承接后重新站上触发价】同时成立，才按给定区间买入；任一条件不成立全部弃买。
```

## 合格与弃买形态示意

```text
合格：回踩承接后重新转强
价格                       放量突破触发价 ← 买
  │              ┌────────●
  │        ╲____╱
  │         缩量回踩、不破关键支撑
  └────────────────────── 时间

弃买：高开冲顶后单边回落
价格       ●
  │       ╱ ╲________
  │      ╱             持续走低 ← 不买
  └────────────────────── 时间
```

## 推荐输出模板

```text
📅 数据基准：YYYY-MM-DD 收盘快照
依据(≤3行): ...

打法(≤3条，均具名):
1、低位进攻(条件预案): A股 000001 买入X.XX~X.XX|止损X.XX|目标X.XX|仓位10%；备选:B股 600000 买入...；仅当<市场触发条件>时执行，否则全部弃买
2、在手持仓(持仓防守): <真实持仓及具体价格动作>
3、高位只卖不买(防守名单): 龙头A 000000(N板)、龙头B 600000(N板)；无先手绝不接力

红线: <总龙断板/指数破位条件>；触发后只卖不买。
```

## 回归验收

- 测试历史快照不会被当前 `market_regime.json` 污染。
- 测试防守快照仍返回两只具名具价条件预案。
- 测试低位候选排序稳定，不依赖输入顺序。
- 实跑标准命令，确认 stdout 包含数据日期、买入区间、止损、目标、仓位、弃买条件和高位防守名单。
