# 盘中持仓mini分析模板

盘中评估 Step 0.5B 使用。6维度精简版，每只持仓快速扫描。

## 数据采集（并行）

1. `mcp_intel_query_data(symbol)` → 实时价、涨跌幅
2. `mcp_intel_fetch_kline(symbol, period="30", count=10)` → 近10根30分钟K线（看今日分时走势）
3. `mcp_intel_search_news(symbol)` → 突发消息
4. **Jin10 `search_flash(symbol名)` → 个股快讯（补充 intel search_news 可能遗漏的即时消息）**
5. **Jin10 `list_flash` → 全球实时快讯（判断外围市场联动，如港股/韩股/美股期货涨跌）**

## 输出格式

### ⚠️ 用户统一盯盘报告格式（6/26确立，所有单票监控必须遵守）

当用户要求盯单只个股（如"分析XX"、"监控XX"），或盘中监控cron触发时，严格按以下6段式输出，不可省略任何段落：

```
---
## [股票名]（代码）走势分析报告
**分析时间：** {北京时间 HH:MM}
**最新价：** {现价}元
**涨跌：** {涨跌额}元 ({涨跌幅}%)
---
### 一、基本行情数据
| 指标 | 数值 |
|------|------|
| 今开 | {今开}元 |
| 昨收 | {昨收}元 |
| 最高 | {最高}元 |
| 最低 | {最低}元 |
| 振幅 | {振幅}% |
| 换手率 | {换手率}% |
| 成交量 | {成交量}万股 |
| 成交额 | {成交额}亿元 |
---
### 二、近期分时成交情况
**成交明细（最近10分钟）：**
（列出最近10条1分钟K线的关键价位和成交量）
---
### 三、关键位置对比
| 位置 | 价格 | 与现价关系 |
|------|------|------------|
| 成本价 | {成本} | {现价vs成本} |
| 5日线支撑 | {5日线} | {现价vs5日线} |
| 今日高点 | {今日高} | - |
| 今日低点 | {今日低} | - |
---
### 四、出货/洗盘特征判断
#### 🔍 判断依据：
**出货特征：**
- {❌ 列出出货信号}
**洗盘特征：**
- {✅ 列出洗盘信号}
#### ⚠️ 判断结论：{洗盘/出货/正常波动}
---
### 五、操作建议
📌 **建议：** {持有/减仓/清仓/加仓}
**理由：**
1. {理由1}
2. {理由2}
3. {理由3}
---
### 六、风险提示
⚠️ **特别提醒：**
- 解禁倒计时：{日期+数量+占比}（距离解禁还有{天数}天）
- 当前浮亏/浮盈：{计算}
- {其他：PE、板块波动等}
```

**关键约束**：
1. 6段必须齐全，不可省略或合并
2. 第四段出货/洗盘判断必须用 ✅/❌ 符号逐条列出，给出明确结论
3. 第五段操作建议只能是：持有/减仓/清仓/加仓 四选一，附理由
4. 第六段必须包含解禁倒计时（如有）、浮亏/浮盈计算
5. 此格式适用于：单票监控cron、手动盯盘请求

### 6维度精简版（仅用于持仓快速扫描，非单票盯盘场景）
### [股票名] 现价XX (+X.XX%)｜成本XX｜浮盈/亏X.X%

1️⃣ 分时走势：开盘→现在的走势特征（冲高/回落/横盘/拉升）
2️⃣ 资金面：所属板块今日资金流向 + 个股成交额
3️⃣ 大盘关联：market_phase下该板块的表现
4️⃣ 成本位：距止损/止盈的距离%
5️⃣ 浪型状态：盘前判断的浪型，盘中是否有变化
6️⃣ 操作建议：持有/减仓/止盈/止损 + 触发条件

风险定级：🟢安全 / 🟡关注 / 🔴紧急
```

## 风险定级标准

### 通用标准（10:00 / 13:30）
- 🟢安全：止损位距离 > 5%，趋势向上
- 🟡关注：止损位距离 2~5%，或浪型转换窗口
- 🔴紧急：距止损位 < 2% / 盘中突发重大利空 / 所属板块资金大幅流出（>30亿）且个股跟跌

### 尾盘增强标准（14:15 专用）
- 🟢安全：止损位远，全天趋势健康
- 🟡关注：止损位距离 3~5%，或尾盘走势犹豫
- 🔴紧急：距止损位 < 1.5% / 尾盘跳水（最后30分钟跌幅 > 2%）/ 板块尾盘资金大幅流出 / 重大利空尾盘发布

## 综合输出

```
【持仓风险速览 HH:MM】
| 股票 | 现价 | 涨跌 | 浮盈亏 | 浪型 | 风险级 | 操作建议 |
|------|------|------|--------|------|--------|---------|
```

🔴紧急标的 → 直接生成 TradeIntent（direction: sell），进入 Step 2→3→4

## 14:15 尾盘额外字段

尾盘检查增加"尾盘信号"和"尾盘操作"：

```
5️⃣ 浪型状态 + 尾盘信号：[拉升抢筹/跳水出货/横盘等待]
6️⃣ 尾盘操作：立即执行/持有过夜/明天再决定
```

⚠️ 14:15 的卖出委托要在 14:20 前执行，否则尾盘滑点风险大。
⚠️ 14:15 新开仓上限 3%（更保守），time_horizon 强制 1d。
