## 设计模式

### Cron 配置

```
name: "股票名-日期监控"
schedule: "*/15 1-7 DD MM DOW"  # 仅当天盘中 9:30-15:00
deliver: "origin"  # 自动投递到当前对话
enabled_toolsets: ["terminal", "file", "web", "search"]
model: anthropic/claude-sonnet-4  # 响应短且稳定
```

## 核心步骤
1. 调用 mcp_intel_query_data("{代码}") 获取最新行情
2. 调用 mcp_intel_fetch_kline("{代码}", period="1", count=30) 获取最近30根1分钟K线
3. 调用 mcp_exec_get_today_trades() 检查当日是否有成交
4. 按下方模板输出报告

### 阈值设置参考

| 指标 | 正常范围 | 触发阈值 |
|------|---------|---------|
| 5分成交量 | 5-40万 | >50万或<2万 |
| 涨跌幅 | -3%~+5% | >7%或<-5% |
| 价格区间 | 关键位之间 | 突破/跌破关键位 |

## 优点

1. **格式统一**：所有盯盘报告使用同一格式，用户一目了然
2. **自动成交检测**：每轮检查当日成交，有成交自动追加交易报告
3. **轻量**：每15分钟一次，3个MCP调用（行情+K线+成交）
4. **可定制**：关键参考位/触发条件按需调整

## 关键原则

1. **必须拉MCP实时数据**：先 query_data + kline，再输出分析
2. **1分钟K线用于分时**：用 period="1" 获取���近30根分钟K线
3. **成交检测**：每轮调用 get_today_trades() 检查当日成交
4. **格式严格**：按照统一模板输出，不可省略板块

**背景**：6/26盘中监控，成本价107.60（400股），7/1解禁1.93亿股。

**cron配置**：job_id=ff344893a67c，每15分钟，模型claude-sonnet-4
