# 板块共振·低位中军放量突破模式

## 适用场景

用于盘中每5分钟扫描：题材已有涨停标杆或两只以上强势股时，寻找尚未加速、流动性充足的低位中军，在真实放量突破前一交易日高点时触发。

该模式源于康强电子案例。案例证明了发现能力，但由于当时未形成完整价格计划和真实委托，结论只能是：**研究成功、执行失败、实际收益为0**。单个成功案例只允许形成待验证模板，不能直接标为高胜率策略。

## 硬筛选条件

1. 题材评分不低于60。
2. **正式买入信号**要求同题材至少3只涨幅≥3.5%；仅有2只强势股时，即使存在封板标杆，也只进入影子池，不形成买入推送。
3. 候选未涨停，当日涨幅通常为+2.5%至+7.0%；+6.5%以上在质量评分中降权，防止追高。
4. 现价严格突破前一交易日最高价。
5. 现价距日内最高价回撤≤0.8%；≤0.5%才允许正式信号，0.5%~0.8%只进影子池。
6. 成交额≥8000万元；正式信号成交额≥3亿元，8000万~3亿元只进影子池。
7. 时间归一化预计全天量比须处于1.5~3.5；>3.0降级影子池，>3.5判定过热并拒绝。缺历史成交量时不得把普通突破描述为“放量突破”。
8. 上方主要阻力空间≥3.5%，预期盈亏比≥2:1。
9. 14:30后不新增买入；sell-only、冰点、策略冷却或风控拒绝时只做影子跟踪。
10. 同板块不再机械只取“成交额+涨幅”前2名；正式候选按板块广度、距高点回撤、健康量比、流动性和涨幅位置综合排序，只输出质量第一名。

## 时间归一化量比

盘中累计成交量不能直接与完整交易日比较。应按连续竞价已运行分钟数折算：

```text
elapsed = 上午已交易分钟 + 下午已交易分钟
projected_full_day_volume = current_volume × 240 / elapsed
volume_ratio = projected_full_day_volume / 前5个完整交易日平均成交量
```

午休不计入 elapsed；缺失、零值和未开盘状态一律返回未确认，不得猜测。

## 价格计划

触发价为 `P`：

- 买入区间：`P` 至 `P×1.012`，超过上沿不追。
- 初始止损：`max(昨日前高×0.985, P×0.965)`。
- 第一减仓：`P×1.08` 或下一主要阻力位，取更保守者。
- 初始仓位：样本不足5个前最多15%试错仓。
- 加仓：仅限突破后缩量回踩前高不破，再次放量上穿。
- 弃买：跌回昨日前高、距日内高点回撤>0.8%、板块共振消失、超过买入上沿或风控拒绝。

任何用户可见信号必须同屏给出名称/代码、触发价、买入区间、止损/清仓价、第一减仓价、仓位、触发条件、弃买条件和执行状态。

## 发现与执行分层

发现层先写 `shadow_candidate`：

```json
{
  "record_type": "shadow_candidate",
  "catalyst_type": "sector_volume_breakout",
  "direction": "buy",
  "quantity": 0,
  "execution_status": "SIGNAL_ONLY",
  "awaiting_llm_review": true
}
```

同时保存 `prior_high`、`volume_ratio`、买入区间、止损、目标、板块证据和时间戳。发现层不得写成真实持仓，不得让卖出监控消费影子仓。

只有补齐实时行情、量价、板块、新闻、基本面和结构证据后，才升级为正式 candidate，并进入：

`candidate → risk approval → approved intent → order → order-id回查 → filled position → exit → outcome`

只有 `order_id + filled_price + quantity>0` 才能标为 `HOLDING_REAL`。否则后续即使涨停，也只能记录实际收益0。

## 盘中热点中军两周代理回测校准（2026-09-29）

`intraday_hot_sector_sniper.py` 的日终无未来函数代理回测覆盖2026-09-16至09-29：严格资金正流入且排除涨停后23只，胜率39.13%、平均收益-1.04%、平均MFE+3.08%、平均MAE-5.22%。分层发现：龙头首板阶段胜率60%、平均MAE-3.39%；龙头≥2板时胜率23.1%、平均MAE-6.63%；涨幅≥6%胜率仅16.7%；资金门禁取消后胜率降至21.74%。因此生产入口执行以下硬校准：

1. 正式候选涨幅收紧为+1%至+6%，已涨停/准涨停不归入中军买入。
2. 主力资金必须明确净流入；字段缺失只记影子观察，不进入执行池。
3. 龙头仍处首板发酵期才允许正式中军候选；龙头≥2板仅影子跟踪，防止高潮后接盘。
4. 止损改为 `max(现价×0.96, MA50×0.985)`，MA50不得把风险放宽到4%以上。
5. 第一减仓目标由统一+10%下调为+4%，匹配过去两周平均MFE；后续是否提高目标由前瞻分钟级样本决定。
6. **容灾不得绕过门禁**：问财和TDX都无数据时，腾讯直连只能负责发现候选；候选必须补上 `main_net_flow=None` 并重新调用统一分类器，因此只能成为 `shadow_candidate/SIGNAL_ONLY/quantity=0`，不能直接返回正式候选。
7. **报告文案属于生产合约**：代码阈值调整后，要同步搜索用户可见文案中的旧涨幅区间、目标和止损说明。否则会出现代码执行+1%~+6%，报告却仍声称+0.2%~+13%的自相矛盾。

### 最小回归案例：容灾防穿透

构造问财与TDX均为空、腾讯容灾返回一只价格和涨幅合格但无资金数据的股票。修改前该候选会直接从容灾分支返回并进入执行池；修改后预期：

```text
formal candidates = []
shadow candidates = [候选]
tier_reason = fund_flow_missing
```

测试必须先失败，证明真实覆盖了容灾旁路；实现时不要在每条数据源分支复制门禁，应统一调用正式/影子/拒绝分类器。

本结论只适用于盘中热点中军策略，不覆盖1进2/2进3龙头接力策略；龙头生命周期策略仍由独立入口管理。

## 回测优化依据（2026-09）

历史样本111只的基线胜率54.95%、平均收益+1.22%；按板块强势股数量分层后：

- 强势股≥3：82只，胜率60.98%，平均收益+1.78%，止损22只；
- 强势股≥4：63只，胜率65.08%，平均收益+2.14%，止损14只；
- 强势股≥5：43只，胜率67.44%，平均收益+2.43%，止损10只；
- 仅2只强势股：29只，胜率37.93%，平均收益-0.36%。

因此，板块强势股≥3升级为正式信号硬门槛，≥5只在质量评分中获得更高优先级；仅2只强势股不得正式买入。旧版按“成交额+涨幅”机械取前2名曾将胜率降至48.78%并漏掉康强电子，已废除。

## 统计升级规则

按 `sector_volume_breakout` 单独记录触发时间、触发价、MAE、MFE、1/3/5日收益、止损与目标先后顺序、板块梯队和执行断点。

- 样本<5：观察期，不提高仓位。
- 样本≥5且胜率<40%：降低置信度并复审。
- 连续两笔真实亏损或单笔重伤：交给物理熔断器。
- 连续3个A级样本且平均盈亏比达标：才允许提高优先级。

## 上线与验收清单

回测结论不能停留在文档层。每次优化必须逐项验证：

1. 生产盘中脚本已采用新的板块广度、量比、回撤、流动性和排名规则；确认修改的是 cron 实际调用入口，不是同名实验脚本。
2. 先写失败测试再改实现，保留 RED→GREEN 证据；测试至少覆盖：正式信号、影子信号、过热拒绝、弱板块拒绝、健康候选排名优于追高候选。
3. 影子候选只写研究台账，`quantity=0`、`execution_status=SIGNAL_ONLY`，不得进入买入推送、卖出监控或真实收益统计。
4. 正式信号必须输出名称/代码、触发价、买入区间、止损/清仓价、第一减仓价、仓位、触发条件、弃买条件和成交状态。
5. 执行目标测试与语法检查，并用实际 diff 或配置核对生产入口已引用新逻辑；只更新 Skill、只产出回测报告或只修改测试都不能称为上线完成。
6. 对用户汇报必须给出 Before/After 量化证据；若发现此前仅完成分析而未落盘，应直接补齐，不得继续沿用“已更新”的表述。

## 回归验收

- 时间归一化量比有确定性单测。
- 无封板标杆且强势股不足2只时，突破候选被清空。
- 影子候选 quantity=0、SIGNAL_ONLY，不产生虚假持仓。
- 报告包含买入区间、止损、第一减仓和弃买条件。
- 非交易时段运行静默且不写买入候选。
