# 卖点LLM审核完整决策标准（否决项优先）

## 卖出审核决策树

### 第一步：是否跌破成本线 | 止损线
- 破止损-6%~-15%等 → 立即卖出（不分趋势）
- 接近止损 → 注意保护，找反弹减仓

### 第二步：是否利空新闻（最高优先级）
- 业绩暴雷/减持/监管/诉讼 → 必须卖
- 正常波动/情绪性下跌 → 看第三步

### 第三步：趋势与量价保护
- ⛔ 上升通道中的正常回踩 → 不卖（保护性否决，决定性）
- ⛔ 缩量回调不卖 → 惜售，上升延续
- ⛔ 大级别买点附近 → 不卖
- ✅ 放量跌破关键支撑 → 卖
- ✅ 顶背驰 + 放量滞涨 → 卖

## 买入审核检查清单（含2026-08-31 量价背离硬否决）

### 否定项（任何一条触立即REJECT）
1. ⛔ 放量下跌/高开低走收阴 → 多头陷阱
2. ⛔ 振幅>5%却收跌 → 典型出货形态
3. ⛔ 风控超时(timed out) → 硬拒绝，不可绕过
4. ⛔ 下降通道中的反弹 → 非买点
5. ⛔ 概念炒作无真实量产/订单 → AI周线热点不炒

### 确认项（至少3条满足才APPROVE）
1. ✅ 缠论有效买点（一买/二买/三买/类二买）
2. ✅ 缩量回踩支撑不破 + 次日放量企稳
3. ✅ 放量突破 + 缩量回踩确认
4. ✅ 实质性利好（订单、量产、业绩改善、政策）
5. ✅ 板块资金流入
