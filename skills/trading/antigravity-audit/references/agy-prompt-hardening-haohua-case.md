# 昊华科技买入案 — AGY Prompt 硬化

## 案例背景

2026-08-31，`intraday_leader_monitor.py` 触发荣昌生物二买确认，AGY批准买入。同日 `close_session_scan.py` 判定荣昌生物三卖，先卖出——用户质疑"为什么又买又卖，让我很茫然"。

随后AGY审计发现昊华科技买入仍存在同类问题（AGY prompt缺失量价数据、*_confirmed硬编码True绕过风控）。

## Root cause chain

| 层 | 问题 | 严重度 |
|----|------|--------|
| AGY prompt | 只有"趋势与量能"概括描述，没有原始量价数字 | P0 — AGY无法判断量价背离 |
| 代码 | `*_confirmed=True` 硬编码，绕过板块/基本面/新闻风控 | P0 — AGY批准即无条件执行 |
| 代码 | thesis前缀只认`[缺口逻辑]`，龙头股`[缠论]`/尾盘`[尾盘]`被静默过滤 | P1 — 龙头股买点被误杀 |
| 管道 | `close_session_scan.py` 卖出候选直接写闸门，不走LLM二审 | P0 — 卖出绕过深度审核 |

## 修复对照

| 维度 | 修复前 | 修复后 |
|------|--------|--------|
| AGY buy prompt 量价 | "趋势与量能：量能配合良好" | 实时量价行：最新价+涨跌幅+成交量+成交额+对比昨日量比 |
| 硬否决条件 | 无 | 放量下跌/高开低走收阴/振幅>5%却收跌 → 直接REJECT |
| 缩量回踩 | 不区分 | 缩量回踩不破支撑+次日放量企稳 → 真买点 |
| thesis前缀 | 仅`[缺口逻辑]` | `[缺口逻辑]/[缠论]/[尾盘]` 三种 |
| *\_confirmed | True 硬编码 | False 默认，AGY通过走 `llm_approved` 豁免路径 |
| sell候选 | 直接写闸门 | `awaiting_llm_review: true` 走LLM二审 |

## 核心教训

AGY prompt 设计铁律：AGY需要**原始数据自己判断**，不要给概括性结论。两条具体规则：

1. **量价行必填**：最新价、涨跌幅、成交量、成交额、与昨日的量比（`今日成交额/昨日成交额`）。没这些数字，AGY无法判断放量下跌还是缩量回调。
2. **硬否决条件直接写**：不要只说"注意量价背离"——直接写代码级硬条件。AGY会严格遵守写明的REJECT条件，但会忽略模糊的风险提示。

## 触发方式

当任意盘中cron的buy prompt需要修改时，加载本参考检查是否包含了量价行和硬否决条件。任何不包含实时量价数据的AGY buy prompt都是不完整的。

## 验证方法

```bash
# 检查当前 prompt 是否包含量价行和硬否决条件
grep -n "放量下跌\|高开低走\|振幅>5%\|量同比" intraday_leader_monitor.py
```
