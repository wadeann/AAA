# Ignition-V1 2026-09-14 审计：单位换算Bug + 字段兜底模式

## 背景

Ignition-V1 首板狙击系统，V2.1 版。129行CONFIG + 评分780行 + 竞价80行 + 退出70行。
盘后问财扫描→6维评分(80满分)→Top 150候选→次日竞价确认→T+1退出。

## 发现的P0 Bug

### P0 Bug1: free_market_cap 虚高10倍 (cap_mult=15)

**位置**: `ignition_v1_sniper.py:44`  `"market_cap_turnover_multiplier": 15.0`
**根因**: 问财不返回流通市值字段(l.705-706退化为0)，代码退到 `amt * cap_mult`(l.758)。`amt` 已是**元**（神宇8.5亿=852,493,653元），乘15=127.9亿，但真实流通市值约12.8亿。
**如何发现**: 127.9亿/8.5亿 ≈ 15.04 ≈ cap_mult ✓ 但真实市值12.8亿÷8.5亿≈1.5
**修复**: `15.0 → 1.5`
**验证**: 8.5亿×1.5=12.75亿 ✅ 匹配真实流通市值

### P0 Bug2: industry 全程为空

**位置**: `ignition_v1_sniper.py:710`  `d.get("所属同花顺行业", d.get("所属行业", ""))`
**根因**: 问财不返回"所属同花顺行业"字段。150只候选 `industry=""`。
**影响**: 板块热度计算全失效、题材雷达无法匹配。
**修复**: 三级兜底 `d.get("所属同花顺行业") or d.get("所属行业") or d.get("同花顺概念", "")`

### P0 Bug3: 距离分负值无条件通过

**位置**: `ignition_v1_sniper.py:440-441`
**代码**: `dist = (highest-close)/close*100` 随后 `if dist <= 2: score_dist = 20`
**根因**: 当close>highest(突破前高)，dist为负数。dist<=2通过没问题但逻辑隐晦。
**修复**: 新增分支 `if dist < 0: score_dist = 20  # 突破前高创新高，满分`
